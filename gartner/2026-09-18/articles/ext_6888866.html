어떤 프레임워크를 어떻게 고를까

핵심 발견

AI 에이전트 개발 프레임워크는 AI 에이전트와 에이전트형 응용 소프트웨어의 구축을 간소화한다. 다양한 기능과 연계를 제공해 개발을 더 쉽게 만든다. 대규모 언어 모델, 확장된 문맥 창, Model Context Protocol(MCP)과 Agent2Agent(A2A)의 빠른 확산이 AI 에이전트의 기반을 강화하고 있다. 다만 프레임워크가 빠르게 진화하는 가운데 비결정성, 가드레일 부재, 보안·규제 위험이 함께 커져 새로운 개발 관행과 역량이 필요하다. 또한 선택지가 매우 넓어 소프트웨어 엔지니어링 팀은 용도에 맞는 프레임워크를 신중히 골라야 하며, 다수의 오픈소스 프레임워크는 경쟁 압력으로 상용 라이선스와 상용 확장으로 이동하고 있다.

권고 사항(Recommendations)

AI 에이전트 개발 경험을 쌓기 위해 범위가 명확하고 위험이 낮은 내부 소프트웨어 엔지니어링 용도부터 시작한다. 프레임워크는 생태계 접근성, 도구 범위, 메모리 요구사항, 사용 편의성, 다중 에이전트 지원, 코드 실행 능력 등 필요 기준에 맞춰 선택하고, 원하는 결과를 위해 여러 프레임워크를 조합해 사용한다. 팀 내에서 프롬프트 엔지니어링, Python 기초 지식, API 보안 같은 AI 특화 개발 관행과 역량에 투자해 안전한 AI 에이전트 시스템을 구축·운영한다. 대규모 언어 모델 수준과 AI 에이전트 수준 모두에서 평가, 보안, 거버넌스, 모니터링 역량을 포괄적으로 마련해 보안을 강제한다.

전략 계획 가정(Strategic Planning Assumption)

2028년까지 조직의 80%는 개발자보다 AI 에이전트가 자사 API의 대부분을 소비한다고 보고할 것이다.

서론

AI 에이전트의 부상으로 인공지능 분야는 큰 전환을 겪고 있다. AI 에이전트는 대체로 대규모 언어 모델을 기반으로 하며, 목표를 자율적으로 이해하고 행동을 계획하며 환경과 상호작용해 복잡한 과업을 최소한의 인간 개입으로 수행하도록 설계된다. 2025 Gartner AI in Software Engineering Survey에 따르면 상위 성과 조직의 소프트웨어 엔지니어링 팀은 하위 성과 조직보다 AI 에이전트 구축을 전적으로 맡을 가능성이 훨씬 높다. 이런 시스템을 처음부터 만드는 일은 매우 복잡하기 때문에, 생성·오케스트레이션·배포를 단순화하는 구조화된 접근과 추상화를 제공하는 AI 에이전트 개발 프레임워크가 등장했다.

정의

AI 에이전트는 디지털 또는 물리적 환경에서 인공지능 기법을 사용해 인지하고, 의사결정하고, 행동하며, 목표를 달성하는 자율형 또는 반자율형 소프트웨어 개체다. AI 에이전트 개발 프레임워크는 AI 모델 기반 오케스트레이션을 위한 고수준 추상화와 함께 에이전트 논리, 메모리, 계획, API 접근에 대한 저수준 제어를 제공해 복잡한 과업을 자율 수행하는 AI 에이전트와 AI 기반 응용 소프트웨어의 개발을 가속하도록 설계된다. 이들 프레임워크가 추상화하는 핵심 기능에는 계획과 추론, 메모리 관리, 도구 사용, 행동·관찰 반복 관리, 다중 에이전트 조정이 포함된다. 그림 1은 AI 에이전트 개발 프레임워크의 주요 구성요소를 제시한다.

핵심 구성요소

핵심 구성요소에는 오케스트레이션, 다중 에이전트 작업 흐름, 내장 도구, MCP 클라이언트, 메모리, 모델 연계 또는 대규모 언어 모델 연결기, 코드 실행, 언어 실행 환경이 포함된다. 오케스트레이션은 대규모 언어 모델과 도구를 활용해 API 호출, 메모리 접근, 다른 에이전트와의 협업을 관리하고, 다중 에이전트 작업 흐름은 에이전트 간 상호작용의 순서와 흐름을 정의한다. 내장 도구는 검색 증강 생성(retrieval-augmented generation, RAG) 파이프라인과 외부 API를 포함한 외부 세계와의 상호작용을 가능하게 하며, MCP 클라이언트는 MCP 서버 연계를 제공한다. 메모리는 문맥 유지와 장기 기억을 돕고, 모델 연계는 하나 또는 여러 대규모 언어 모델의 선택을 가능하게 하며, 코드 실행과 언어 실행 환경은 동적 코드 생성과 Python, JavaScript, .NET, Java 같은 주요 개발 언어와의 호환성을 지원한다.

개발자 도구

선택적 구성요소로 시각 편집기, 가시성 확보와 모니터링, 평가(테스트) 도구가 제공된다. 시각 편집기는 다중 에이전트 시스템과 아키텍처 패턴을 시각적으로 구성하게 해 개발을 단순화한다. 가시성 확보는 신뢰성, 비용 관리, AI 안전성을 위해 에이전트 내부 동작에 대한 통찰을 제공하고, 외부 도구 호출 추적과 문제 재현을 돕는다. 많은 프레임워크는 AutoGenBench, LangSmith, OpenEvals 같은 외부 평가 도구와의 연계를 포함해 테스트, 성능 추적, 실험 수행 기능을 제공하며, 모든 핵심 구성요소와 개발자 도구가 반드시 같은 공급업체나 프레임워크에서 나올 필요는 없다.

AI 에이전트 개발 프레임워크의 이점

AI 에이전트 개발 프레임워크는 복잡한 AI 시스템 구축을 단순화하고, AI 모델 상호작용·메모리 관리·작업 흐름 오케스트레이션 같은 세부를 추상화해 개발자가 핵심 기능에 집중하게 한다. 저코드 플랫폼이나 무코드 생성기와 비교하면, 독립형 AI 에이전트와 복잡한 다중 에이전트 시스템을 만들 수 있는 완전한 프로코드 개발의 유연성과 제어력을 제공한다. 통합된 프레임워크를 채택하면 반복 코드가 줄고 팀 간 표준 관행이 생겨 개발과 협업이 더 원활해진다. 또한 이미지-텍스트 변환, 웹 스크래핑, 코드 해석기, 다른 AI 에이전트 등 다양한 도구와의 연계를 제공해 에이전트가 복잡한 과업을 자율적으로 수행하도록 돕는다.

AI 에이전트 개발 프레임워크의 활용

이 프레임워크는 단일 AI 에이전트 구축, 다중 에이전트 오케스트레이션 구축, 기존 응용 소프트웨어에 AI 에이전트 내장 같은 다양한 용도를 지원한다. 단일 AI 에이전트는 단순하거나 중간 수준의 복잡도를 가진 과업에 적합하며, Langchain처럼 다단계 작업 흐름과 단독 에이전트 구조를 지원하는 프레임워크가 효율적이다. 다중 에이전트는 중간에서 높은 복잡도의 과업을 위해 독립 애플리케이션 또는 서비스로 동작하며, Google이 개발해 Linux Foundation에 기증한 오픈소스 A2A 같은 에이전트 간 프로토콜로 통신한다. 기존 응용 소프트웨어에 내장할 때는 Spring Boot와 .NET Core(via AutoGen) 같은 기존 개발 프레임워크도 활용할 수 있지만, 단일 구조 애플리케이션에 직접 넣는 방식이 항상 최선은 아니므로 조합형 응용 소프트웨어 아키텍처를 고려해야 한다.

위험

AI 에이전트 개발 프레임워크는 빠르게 성장하는 초기 단계 기술이어서 오픈소스 공동체가 불안정하고, 다수가 1.0 미만 버전으로 빠르게 변해 호환성이 깨지는 변경을 일으킬 수 있다. 주로 Python으로 작성돼 있어 기업은 Python 개발 역량에 투자해야 하며, 다른 언어 기반 기업용 응용 소프트웨어와의 연계에는 강한 API 기반 통합과 분산 아키텍처가 필요하다. 프레임워크와 기능이 빠르게 바뀌어 소프트웨어 엔지니어링 팀은 낡은 기능의 재구축과 기존 코드의 리팩터링으로 기술 부채를 쉽게 떠안을 수 있다. 또한 프롬프트 주입, 데이터 노출, 악의적 사용자나 상위 입력, 비결정성으로 인한 오류와 규제 준수 문제 등 보안과 신뢰성 위험이 크며, 많은 프레임워크는 이를 위한 내장 가드레일과 강한 디버깅·가시성 확보 도구가 부족하다.

도입률

2025 Gartner AI in Software Engineering Survey에 따르면 AI 에이전트 프레임워크는 AI 에이전트 구축에 사용되는 상위 3대 플랫폼과 도구 가운데 하나로 꼽혔다.

대안

대안으로는 저코드 에이전트 개발 플랫폼, 무코드 에이전트 생성기, 로봇 프로세스 자동화(RPA)와 작업 흐름 자동화가 있다. 저코드 플랫폼은 사전 구축 구성요소와 시각 편집기를 통해 코딩과 아키텍처 복잡성을 줄이고, 오케스트레이션·대규모 언어 모델 연계·메모리 관리를 추상화해 개발과 유지보수를 쉽게 한다. 무코드 생성기는 코딩 없이 AI 기반 에이전트를 구축·공개·관리하는 서비스형 소프트웨어 제품으로, 주로 시민 개발자와 시민 데이터 과학자 같은 비즈니스 기술자가 사용한다. RPA와 작업 흐름 자동화는 실행 환경이 안정적이고 목표가 명확하며 과정이 반복적이고 예외가 적을 때, 고급 에이전트 기반 시스템보다 더 효과적이고 신뢰성 있게 효율성과 일관성을 제공한다.
