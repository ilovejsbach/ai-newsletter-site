파일 데이터 서비스를 어떻게 현대화할까

영향

비정형 데이터가 빠르게 늘면서 I&O 리더는 파일·오브젝트 데이터 플랫폼을 현대화할 새 기술과 제품을 찾고 있다. 생성형 AI(GenAI) 같은 기존·신규 비정형 데이터 애플리케이션은 탄력성, 운영 단순화, AI 처리, 데이터 장기 보존을 위해 퍼블릭 클라우드 활용이 가능한 하이브리드 클라우드 파일 기능을 요구한다. 분산된 업무 인력 확대와 클라우드 이전 추진은 퍼블릭 클라우드 파일 서비스와 이전 방법에 익숙하지 않은 I&O 리더에게 새로운 과제가 되고 있다.

권고 사항(Recommendations)

재해 복구, 용량 확장, 처리 확장, 스토리지 표준화에 퍼블릭 클라우드를 활용해 하이브리드 클라우드 데이터 서비스를 구현한다. 목표, 서비스 수준 협약, 비용 제약에 맞춰 제시된 접근법으로 비정형 파일 데이터를 퍼블릭 클라우드 서비스형 인프라(IaaS)와 통합하는 3개년 계획을 수립한다. 데이터 이동성, 데이터 분석, 사이버 복원력, 수명 주기 관리, 전역 접근성 같은 부가 서비스 제공 역량을 기준으로 하이브리드 클라우드 파일 제공업체를 선택한다.

전략 계획 가정(Strategic Planning Assumption)

2028년까지 I&O 리더의 70%가 최소 1개의 하이브리드 클라우드 스토리지 활용 사례를 구현할 전망이며, 이는 2024년의 30%에서 크게 늘어난 수치다. 2028년까지 기업이 관리하는 데이터의 50% 초과가 데이터 센터나 클라우드 밖에서 생성·처리될 전망이며, 이는 2024년의 25%에서 크게 증가한 것이다. 2028년까지 I&O 리더의 60%가 하이브리드 클라우드 파일 배치를 구현할 전망이며, 2024년 초의 25%에서 상승한다.

서론

비정형 데이터 배치는 규모와 배치 크기 모두에서 그 어느 때보다 빠르게 늘고 있으며, 지난 1년간 Gartner 최종 사용자들은 비정형 데이터가 30%~50% 증가했다고 보고했다. 하이브리드 클라우드 스토리지는 데이터 증가, 디지털화와 세계화, 생성형 AI, 복원력, 클라우드 통합과 이전에 대응하기 위한 필수 요소로 간주되고 있으며, 2023 Gartner I&O Leaders Priorities Survey에서는 응답자의 61%가 하이브리드 클라우드 전략 수립을 최우선 과제 중 하나로 꼽았다. 이 블록의 그림들은 엣지에 구현될 데이터 서비스, 하이브리드 클라우드 시나리오, 퍼블릭 클라우드 인프라를 활용한 파일 서비스 현대화 방식들을 비교해 보여준다. 하이브리드 클라우드 스토리지의 대표 활용 사례로는 재해 복구, 용량 확장, 처리 확장, 데이터 전송, 전역 데이터 오케스트레이션, 스토리지 표준화가 제시된다.

비정형 데이터의 급증과 엔터프라이즈 파일·오브젝트 플랫폼 모색

엔터프라이즈 파일·오브젝트 플랫폼은 전통적 스토리지 제품과 달리 퍼블릭 클라우드 IaaS와 통합하고 이를 활용하도록 설계되며, 모듈형, 소프트웨어 정의형, API 주도형, 분산형이라는 클라우드 네이티브 원칙을 따른다. 기존 및 신규 온프레미스 스토리지 벤더들은 여러 퍼블릭 클라우드 IaaS와의 통합 기능을 확대하고 있지만, 일부는 클라우드 백업 같은 기초적 하이브리드 클라우드 기능에 머물러 있다. 더 발전한 제품은 전체 파일 시스템 또는 오브젝트 스토리지 소프트웨어 스택을 온프레미스, 엣지, 클라우드에서 모두 실행할 수 있게 완전 통합을 제공한다. 이 블록의 그림은 엔터프라이즈 파일·오브젝트 플랫폼의 기초적 기능을 비교한다.

장점

데이터 스토리지 플레인과 하이브리드 클라우드 제어 플레인을 단일 벤더로 운영할 수 있다. 클라우드에서 스토리지를 운영할 때 운영 모델 변경이 비교적 적다. 이미 자리 잡은 온프레미스 솔루션을 활용할 수 있다.

고려 사항

온프레미스 벤더의 독점 기술에 대한 의존성이 생긴다. 일부 벤더는 하이브리드 클라우드 기능이 제한적이다. 이기종 스토리지 환경에는 적합성이 떨어질 수 있다.

공통 활용 사례

주요 활용 사례는 백업과 재해 복구, 용량 확장, 표준화다. 어떤 업무 목적에 맞출지에 따라 적용 방식이 달라진다.

권고 사항(Recommendations)

현재 사용 중인 비정형 데이터 스토리지 벤더와 접촉해 기존 및 향후 하이브리드 클라우드 스토리지 기능을 평가한다. 원하는 사업 성과를 지원할 수 있도록 여러 퍼블릭 클라우드 IaaS와 포괄적으로 통합되는 엔터프라이즈 파일·오브젝트 플랫폼으로 기존 파일 서비스를 교체한다. 엔터프라이즈 파일·오브젝트 플랫폼의 퍼블릭 클라우드 제공 형태와 온프레미스 기능 사이의 성능, 비용, 기능 차이를 이해한다.

기존·신규 비정형 데이터 워크로드와 하이브리드 클라우드 파일 데이터 서비스 필요성

하이브리드 클라우드 파일 데이터 서비스는 온프레미스와 클라우드의 기존 스토리지 솔루션에 하이브리드 클라우드 기능을 추가하는 데 초점을 둔다. 이런 서비스는 대개 더 작은 벤더나 신생 기업이 제공하며, 여러 이기종 비정형 데이터 제품에서 데이터 이동성, 전역 접근성, 이식성, 수명 주기 관리의 공백을 메우는 것을 목표로 한다. 기존 파일 서비스를 대체하기보다 많은 온프레미스 및 퍼블릭 클라우드 솔루션을 보완하는 성격이 강하다. 이 블록의 그림은 하이브리드 클라우드 데이터 서비스를 비교해 보여준다.

장점

여러 온프레미스 파일 시스템과 퍼블릭 클라우드 스토리지 제품을 플랫폼에 구애받지 않고 지원할 수 있다. 데이터 인사이트, 거버넌스, 보안, 비용 최적화를 포함한 폭넓은 하이브리드 클라우드 데이터 서비스를 제공한다. 소프트웨어 혁신과 서비스 확장 속도가 빠르지만, 일부 제품은 단일 활용 사례에만 집중하고 명확한 업무 수요와 투자수익 분석 없이는 추가 비용을 정당화하기 어려우며, 신생 벤더는 지역이나 산업별 실적이 제한적일 수 있다.

공통 활용 사례

주요 활용 사례는 백업과 재해 복구, 용량 확장, 처리 확장, 전역 데이터 오케스트레이션이다. 기존 파일 서비스를 보완하는 방식으로 적용되는 경우가 많다.
