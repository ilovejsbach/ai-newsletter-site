xAI, Grok 4.6으로 장시간 작업 강화

xAI가 Grok 4.6을 발표했다. 이번 버전은 Grok 4.5를 잇는 후속 모델이다. xAI는 긴 단계의 에이전트 작업과 더 복잡한 시각 작업에 초점을 맞췄다고 밝혔다. 코드 작업, 조사, 정보 분석, 앱 제작 같은 흐름을 오래 유지하는 능력을 강조했다.

핵심 브리핑

xAI는 Grok 4.6이 여러 에이전트형 코딩과 지식 업무 벤치마크에서 프런티어 수준 성능을 냈다고 밝혔다. Artificial Analysis Intelligence Index에서는 GPT-5.6 Sol과 같은 61점을 기록했다.

  • 제공처: Cursor, Grok Build, API
  • 파트너: OpenRouter, Vercel, Cloudflare
  • 가격: $2 per million input tokens
  • 가격: $6 per million output tokens
  • fast variant: 기본 가격의 2배
  • 프로모션: 첫 1주일 동안 Cursor와 Grok Build 포함 사용량 2배

xAI는 Grok 4.6이 Grok 4.5보다 더 긴 추가 학습을 거쳤다고 설명했다. 모델이 생성한 추론 데이터, 고품질 엔지니어링 데이터, 개선된 옵티마이저와 학습 방식이 바탕이 됐다고 밝혔다.

후속 단계에서는 Grok 4.5로 SFT 경로를 다시 생성했다. 추론 강도, 에이전트 하니스, STEM, 소프트웨어 엔지니어링, 지식 업무 영역을 반영했고, 문제가 있는 흔적은 모델 기반 점검으로 걸렀다고 했다.

xAI는 Grok 4.6이 긴 작업 경로에서 스스로 시험하고 검증하는 행동을 더 자주 보였다고 설명했다. 시각·인터랙티브 프로젝트의 첫 결과물도 Grok 4.5보다 강해졌다고 덧붙였다.

주요 트렌드

이번 발표는 모델 경쟁의 초점이 단일 질문 응답에서 장시간 작업으로 옮겨가고 있음을 보여준다. xAI는 한 번에 잘 답하는 능력보다, 긴 코드베이스와 반복 피드백 속에서 버티는 능력을 전면에 내세웠다.

유통 경로도 넓다. 자사 도구인 Grok Build뿐 아니라 Cursor, OpenRouter, Vercel, Cloudflare를 함께 언급했다. 개발 도구와 배포 플랫폼을 동시에 잡으려는 전략으로 읽힌다.

가격은 비교적 단순하다. 기본형과 더 빠른 변형을 나눠 속도 차이를 별도 상품으로 팔겠다는 뜻이 분명하다.

업계의 움직임

관련 보도는 아직 많지 않지만, MarkTechPost가 같은 사건을 별도로 다뤘다. xAI는 배포 첫날부터 Cursor와 여러 API 파트너를 함께 내세워 초기 사용을 끌어올리려는 움직임을 보였다. 공개된 고객 사례나 장기 도입 반응은 아직 확인되지 않았다.

시사점과 체크포인트

우리 회사가 볼 지점은 긴 업무 흐름에서의 안정성이다. 예를 들면 규정 해석 조사, 여러 파일을 넘나드는 코드 수정, 보고서 초안 작성 후 반복 수정 같은 작업이다.

평가 항목은 짧은 Q&A와 달라야 한다.

  • 10단계 이상 작업에서 맥락을 잃지 않는가
  • 도구 호출 실패 뒤 스스로 복구하는가
  • 초안 품질보다 수정 반복 횟수가 줄어드는가
  • 시각 결과물이 실제 현업 문서 기준을 맞추는가

가격은 공개됐지만, 한국어 성능과 금융 도메인 안전성 평가는 본문에 없다. API 사용 시 데이터 처리 정책도 별도 확인이 필요하다. fast variant가 두 배 가격인 만큼, 속도 이득이 있는 업무부터 좁게 시험하는 편이 낫다.

주요 용어

SFT(Supervised Fine-Tuning): 정답 예시를 주고 모델을 다듬는 후속 학습 RL(Reinforcement Learning): 보상 신호를 바탕으로 모델 행동을 조정하는 학습 AA Intelligence Index: 여러 벤치마크를 합친 종합 평가 지표 API(Application Programming Interface): 다른 프로그램이 모델을 호출하게 해주는 연결 규칙 에이전트 하니스(Agent Harness): 도구 호출과 실행 흐름을 묶은 평가·운영 환경
