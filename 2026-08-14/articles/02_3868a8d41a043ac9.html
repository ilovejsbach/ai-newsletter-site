OpenAI API, Ultrafast 모드 제한 공개

Cerebras와 OpenAI가 OpenAI API용 Ultrafast Mode를 공개했다. 이 모드는 일부 고객에게 먼저 열린다. 핵심은 GPT-5.6 Sol을 더 빠르게 돌리는 새 서비스 계층이라는 점이다. 두 회사는 품질 저하 없이 실시간에 가까운 속도를 제공한다고 밝혔다.

핵심 브리핑

Ultrafast Mode는 OpenAI API에서 먼저 시작하는 새 서비스 계층이다. 현재는 일부 고객에게만 제공하며, 접근 범위는 점차 넓힐 계획이다.

  • 최대 출력 속도: 초당 750 output tokens
  • 제공 방식: OpenAI API의 Ultrafast Mode
  • 초기 공개 범위: select group of customers

Cerebras는 GPT-5.6 Sol이 이 모드에서 Fable 5보다 11배 빠르고, Opus 4.8의 Fast mode보다 5배 빠르다고 설명했다. 품질은 유지한다고 주장했다.

Humanity's Last Exam 비교도 제시했다. GPT-5.6 Sol Ultrafast는 2,500개 문항을 11시간 11분에 처리했고, Claude Fable 5는 78시간 27분이 걸렸다.

경제적 가치가 있는 지식 업무를 보는 GDP-Val에서도 속도 개선 수치를 공개했다. Ultrafast는 품질 저하 없이 종단 간 속도를 5.6배 높였다고 밝혔다.

Cerebras는 이 속도의 배경으로 자사 Wafer-Scale Engine 구조를 들었다. 웨이퍼 크기 칩마다 44 GB SRAM을 넣어 모델 가중치를 칩 안에 유지한다고 설명했고, 토큰은 여러 웨이퍼를 거치며 파이프라인 방식으로 흐른다고 덧붙였다.

주요 트렌드

이번 발표는 프런티어 모델 경쟁이 정확도뿐 아니라 응답 속도로 옮겨가고 있음을 보여준다. 특히 OpenAI가 API 안에 별도 서비스 계층을 두고 속도를 상품화한다는 점이 눈에 띈다.

사업 구조도 달라진다. 모델은 OpenAI가 제공하고, 초고속 추론 인프라는 Cerebras가 맡는다. 모델 회사와 반도체·인프라 회사의 결합이 더 직접적으로 드러난 사례다.

고객 접근은 제한 공개로 시작한다. 이 방식은 성능 홍보와 운영 안정화 작업을 동시에 노리는 전형적 단계다.

업계의 움직임

이 사안은 OpenAI 자체 뉴스룸, GeekNews, Simon Willison 블로그 등 여러 채널이 함께 다뤘다. OpenAI는 GPT-5.6 관련 가이드와 Ultrafast 프리뷰를 별도 글로 묶어 소개했다. 관련 보도는 법률 문서, 금융 모델, 엔지니어링 리포트처럼 시간이 중요한 업무에 초점을 맞췄다.

시사점과 체크포인트

우리 회사라면 먼저 속도가 실제 병목인 업무를 골라야 한다. 예를 들면 보안 관제 요약, 장애 원인 분석, 시장 데이터 기반 리포트 초안 작성, 상담사 보조가 후보가 될 수 있다.

확인할 포인트는 단순 성능보다 운영 조건이다.

  • Ultrafast 접근 권한을 지금 받을 수 있는가
  • 일반 계층 대비 가격 차이는 얼마인가
  • 속도가 빨라도 감사 로그와 재현성은 유지되는가
  • 민감 데이터가 외부 API로 나갈 때 통제 장치가 충분한가

속도 수치는 인상적이지만, 가격과 SLA는 본문에 없다. 우리 업무에서는 최고 속도보다 평균 응답시간과 오류 재시도 비용이 더 중요할 수 있다. 파일럿 때는 품질 유지 주장도 별도 검증해야 한다.

주요 용어

추론(Inference): 학습된 모델이 입력을 받아 답을 만드는 과정 서비스 계층(Service Tier): 같은 API 안에서 성능이나 가격이 다른 이용 구간 SRAM(Static Random-Access Memory): 칩 안에서 매우 빠르게 쓰는 메모리 Wafer-Scale Engine: 웨이퍼 크기 칩 한 장을 크게 쓰는 Cerebras 구조 GDP-Val: 경제적 가치가 있는 지식 업무를 평가하는 벤치마크
