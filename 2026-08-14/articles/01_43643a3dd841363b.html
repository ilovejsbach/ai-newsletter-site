구글, Gemini 3.7 Flash 가격 반으로 낮췄다

구글이 Flash 계열의 새 모델로 Gemini 3.7 Flash를 발표했다. 이번 버전은 코딩과 에이전트 작업에 초점을 맞췄다. 구글은 3.6 Flash 출시 3주 만에 후속 버전을 내놨다. 구글은 개발자 피드백과 알고리즘 개선이 이번 출시 배경이라고 설명했다.

핵심 브리핑

구글은 Gemini 3.7 Flash를 자사의 새 주력 경량 모델로 소개했다. 코딩, 지식 업무, 웹 개발 흐름에서 3.6 Flash보다 성능을 높였다고 밝혔다.

  • 출시 초기 가격: 입력 $0.75/1M tokens
  • 출시 초기 가격: 출력 $3.75/1M tokens
  • 가격 기준: 3.6 Flash의 원래 가격 대비 절반
  • 제공 기간: 올해 말까지

3.7 Flash는 3.6 Flash보다 코드 디버깅과 이슈 해결에서 더 높은 점수를 기록했다. FrontierCode 1.1 Main은 43.6%로, 3.6 Flash의 34.4%보다 높았다. DeepSWE v1.1은 65.3%로, 3.6 Flash의 49.0%를 앞섰다.

웹 개발에서도 프롬프트 수를 줄이고 더 완성된 결과를 냈다. Arena.ai의 WebDev Arena 점수는 1588이었다. 3.6 Flash는 1538이었다.

금융, 법률, 바이오사이언스처럼 문서 밀도가 높은 영역에서도 수치가 올랐다. GDP.pdf 벤치마크는 34.0%를 기록했다. 3.6 Flash는 22.0%였다. AutomationBench는 30.4%였고, 3.6 Flash는 17.0%였다.

구글은 개발 경험도 좋아졌다고 설명했다. 막히는 상황에 더 잘 적응하고, 필요할 때 의도를 더 분명히 묻고, 여러 단계 계획과 도구 호출에 더 신중하게 대응한다고 밝혔다. 구글은 Gemini API, Google AI Studio, Android Studio, Gemini Enterprise Agent Platform, Gemini Enterprise 앱에서 3.7 Flash를 제공한다.

주요 트렌드

구글은 성능 개선보다 가격 정책을 더 강하게 내세웠다. 3.6 Flash 출시 3주 만에 후속 버전을 내놓은 점도 경쟁 속도를 보여준다.

이번 발표는 코딩용 모델과 지식 업무용 모델의 경계를 더 좁힌다. 구글은 금융과 법률 같은 문서 중심 업무, 웹 개발, 에이전트 실행을 같은 제품 메시지 안에 묶었다.

배포 채널도 개발자와 기업용으로 나뉘어 있다. 개발자는 API와 스튜디오에서 바로 시험할 수 있다. 기업 고객은 Gemini Enterprise Agent Platform과 앱에서 접근한다.

구글은 안전 장치도 함께 갱신했다. CBRN과 사이버 공격 악용 방지 장치를 보강했다고 밝혔다.

시사점과 체크포인트

우리 회사라면 문서 이해와 개발 보조를 분리 발주하지 않고 한 모델로 묶을 수 있는지 먼저 볼 만하다. 특히 연차보고서, 규정집, 계약서, 운영 문서처럼 긴 문서를 읽고 후속 작업까지 넘기는 흐름에 맞는지 점검할 필요가 있다.

검토 대상은 두 갈래다. 업무 쪽은 메일 초안, 상태 보고서 갱신, 문서 요약 자동화다. 개발 쪽은 디버깅, 이슈 재현, 코드 수정 제안이다.

확인할 질문도 분명하다.

  • 사내 문서를 넣을 때 데이터 보관 정책은 어떤가
  • API 호출 로그에 민감 정보가 남는가
  • 도구 호출 결과를 누가 검증할 것인가
  • 재시도 횟수 감소가 실제 운영비 절감으로 이어지는가

아직 공개되지 않은 정보도 있다. 지연시간, 한국어 품질, 금융 특화 데이터에서의 실제 오류 유형은 본문에 없다. 파일럿 전에 사내 샘플 업무로 별도 검증이 필요하다.

주요 용어

에이전트(Agent): 목표를 받고 여러 단계로 작업을 수행하는 AI 실행 방식 토큰(Token): 모델이 입력과 출력을 처리할 때 쓰는 기본 단위 벤치마크(Benchmark): 모델 성능을 같은 기준으로 비교하는 평가 모델 카드(Model Card): 모델 성능, 한계, 안전 정보를 정리한 문서 CBRN(Chemical, Biological, Radiological, and Nuclear): 화학·생물·방사능·핵 관련 위험 영역
