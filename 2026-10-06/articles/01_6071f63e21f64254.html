01 OpenAI 게시일 2026.09.29

OpenAI, DevDay 2026서 에이전트와 협업 기능 대거 추가

OpenAI가 연례 개발자 행사 DevDay 2026에서 제품 발표를 한꺼번에 쏟아냈다. 이번 묶음의 중심은 모델 자체보다 에이전트 실행, 협업 공간, 외부 서비스 배포 경로 확대에 있다. 비개발자 관점에서는 ChatGPT가 단순 채팅창을 넘어 팀 업무 허브로 넓어지는 변화로 보면 된다.

핵심 브리핑

이번 발표는 AI가 답변만 내놓는 도구를 넘어, 맡겨 둔 일을 계속 처리하는 에이전트Agent — 사용자를 대신해 도구를 쓰고 여러 단계를 이어서 수행하는 AI 작업 방식로 움직이게 하려는 업데이트다. OpenAI는 ChatGPT를 사람과 에이전트가 함께 일하는 공용 작업면으로 넓히고, 개발자가 12억 주간 이용자에게 네이티브 경험을 직접 배포할 길을 열었다.

OpenAI는 GPT-6.1 Sol이 코딩과 컴퓨터 사용에 강하고, 일반 토큰 가격은 Astra의 5분의 1이라고 밝혔다. Ultrafast는 유료 속도 등급이다. OpenAI는 토큰 생성 속도가 Codex에서 최대 8배, APIApplication Programming Interface — 다른 프로그램이 모델이나 기능을 호출하는 연결 규칙에서 6배 빨라졌다고 자체 수치를 제시했다. Astra는 지금 쓸 수 있고, Sol은 곧 나온다.

  • Agents API는 퍼블릭 베타Public beta — 누구나 써볼 수 있지만 기능과 정책이 바뀔 수 있는 시험 단계로 공개됐다.
  • 기능에는 호스팅 실행, 메모리, 도구, 멀티 에이전트 지원이 들어간다.
  • Agents API의 컴퓨터 사용은 에이전트가 소프트웨어 UI를 직접 조작하게 한다.
  • Decisions API는 제한적 프리뷰Limited preview — 일부 고객이나 파트너에게만 먼저 공개한 미리보기 단계다.
  • Luna를 써서 입력을 분류하고, 요청을 라우팅하고, 미리 정한 답 중 하나를 고른다.
  • Amazon Bedrock Managed Agents는 AWS 안에서 OpenAI 기반 에이전트를 돌린다.
  • Private Intelligence에는 ZDR과 Private Safety Processing이 포함된다.
  • Private Inference 프리뷰는 올가을로 예정됐다.

Codex도 비동기 작업 쪽으로 넓어졌다. Codex Cloud는 노트북이 닫혀 있어도 작업을 계속 돌린다. 기기 간 접근도 지원한다. CLI 업데이트에는 양방향 음성과 /agents 화면이 추가됐다. 프롬프트 편집, 세션 재개, worktree 작업 방식도 바뀌었다.

보안과 협업 기능도 묶어 나왔다. Code Review는 리뷰 화면에서 요약, diff, 변경 질의를 제공한다. 자동 리뷰는 클라우드에서 실행할 수 있다. Codex Security Cloud는 취약점을 스캔하고, 결과를 조사하고, 중복을 제거하고, 수정안을 준비한다. 예약 스캔도 지원한다.

ChatGPT 쪽에서는 협업과 배포 기능이 커졌다. Plugins는 사이드바 항목, 대화형 패널, 파일 뷰어를 지원한다. Figma와 Adobe가 연동 사례를 공개했다. Sites에서도 plugins를 쓸 수 있다. 각 사용자가 자기 데이터와 권한을 직접 연결한다. MCP events는 연결된 앱이 자동화를 트리거하게 한다.

  • Sign in with ChatGPT는 다른 제품에서 ChatGPT 계정으로 로그인하게 한다.
  • 자격이 되는 구독 사용량은 16개 출시 파트너 제품에서도 쓸 수 있다.
  • OpenAI Marketplace는 일부 엔터프라이즈 고객이 약정 금액 일부를 파트너 제품에 쓰게 한다.
  • Baseten도 포함됐다. 오픈소스 모델 접근용이다.
  • Dots는 연결된 앱과 자체 클라우드 컴퓨터를 가진 지속형 에이전트다.
  • 문자 메시지 기능은 곧 추가된다. dot 팀 기능은 추후 계획이다.
  • Specialist dots는 조직 안에서 특정 책임을 맡는 에이전트로 엔터프라이즈 프리뷰에 들어갔다.
  • Microsoft Agent 365 연동은 계획 단계다. Microsoft의 거버넌스와 보안 도구로 specialist dots를 관리하게 한다.

팀 협업 기능도 늘었다. ChatGPT Space는 팀과 에이전트가 파일과 프로젝트 맥락을 함께 쓰는 공간이다. Pages는 팀원과 에이전트가 문서, 차트, 대화형 도구를 함께 편집하는 기능이다. 협업 슬라이드는 몇 주 안에 추가될 예정이다. Teams와 Team Tasks는 작업 공유와 반복 업무 할당을 지원한다. Slack과 Microsoft Teams 안의 ChatGPT는 @ChatGPT 멘션에 답하고 연결 도구도 쓸 수 있다. Meetings plugin은 회의 메모와 액션 아이템을 만든다. 이 기능은 macOS의 Pro·Business용 베타다.

구독과 성능 지표도 함께 나왔다. Pro 500은 Plus보다 사용 한도가 25배 많고 Ultrafast 접근을 포함한다. Pro 200 구독은 다시 열렸다. 새 구독의 허용량은 기존 유지 고객과 다르다. OpenAI는 API 첫 토큰 지연이 45% 낮아졌고, 도구 호출과 워크플로 속도는 30% 넘게 빨라졌다고 밝혔다. 다만 이 수치는 OpenAI 자체 측정이다.

주요 트렌드

이번 발표는 모델 경쟁을 가격과 속도, 배포 채널 경쟁으로 옮긴다. GPT-6.1 Sol의 일반 가격이 Astra의 5분의 1이라면, 고성능 모델을 써야 했던 코딩·에이전트 작업 일부는 더 낮은 비용으로 옮길 수 있다. 반면 최고 속도는 Ultrafast를 유료 등급으로 분리했다. 기본 단가를 낮추고, 지연에 민감한 고객에게는 별도 요금을 받는 구조다.

OpenAI는 개발자 도구 공급자에 머물지 않고, 유통 채널까지 직접 넓히고 있다. ChatGPT 안의 plugins 추천, Sites 지원, Sign in with ChatGPT, Marketplace는 모두 외부 서비스가 OpenAI 계정과 사용자 기반을 활용하게 하는 장치다. 개발자 입장에서는 자체 고객 획득보다 ChatGPT 안 노출이 더 중요해질 수 있다.

파트너십도 눈에 띈다. Amazon Bedrock Managed Agents는 AWS 안에서 OpenAI 에이전트를 쓰게 한다. Microsoft Agent 365 연동 계획은 거버넌스와 보안 도구 쪽 연결을 겨냥한다. OpenAI는 경쟁 클라우드와 협력하면서도, 최종 작업면은 ChatGPT로 묶으려는 모양새다.

커뮤니티 대화에서는 비용 구조의 세부 조건도 바로 쟁점이 됐다. 한 사용자는 캐시 보존 정책이 30분이고, 캐시 쓰기에는 25% 추가 비용이 붙는다고 지적했다. 같은 맥락을 이어 가는 멀티턴 에이전트에는 유리할 수 있지만, 시간이 길어져 캐시가 빗나가면 입력 비용이 다시 커질 수 있다는 뜻이다. 행사 발표의 저가 메시지만 보면 놓치기 쉬운 운영 조건이다.

업계의 움직임

여러 매체와 커뮤니티가 함께 다룬 큰 행사였다. OpenAI 개발자 커뮤니티에서는 Dots 지원 구독, 지역별 출시 제외, Decisions API의 실제 용도, 캐시 비용 구조를 묻는 반응이 이어졌다. 유럽경제지역, 스위스, 영국은 일부 기능 출시 대상에서 빠졌다는 답변도 올라왔다. Figma와 Adobe는 plugins 연동 사례를 공개했다. AWS와 Microsoft 이름이 공식 발표에 들어가며 대형 플랫폼 협력 구도도 분명해졌다.

시사점과 체크포인트

우리 회사 관점에서는 모델 성능보다 세 가지를 먼저 봐야 한다. 첫째는 어떤 데이터가 ChatGPT 쪽으로 넘어가는지 경계를 분명히 하는 일이다. Sites, plugins, Slack·Teams 연동은 편리하지만, 어떤 데이터와 권한이 ChatGPT 쪽으로 넘어가는지 보안팀과 함께 따져야 한다.

둘째는 에이전트와 자동화 기능을 누가 운영하고 책임질지 정하는 일이다. Agents API와 Dots는 반복 업무 자동화에 맞지만, 승인 규칙과 로그 보관, 장애 대응 책임을 누가 질지 먼저 정해야 한다. 특히 UI를 직접 조작하는 computer use는 실수 범위가 넓다. 테스트 계정, 샌드박스, 행위 제한 정책이 선행 과제다.

셋째는 구독형 기능과 API형 기능의 비용 구조를 따져 보는 일이다. Sol의 단가가 Astra보다 낮아도, 실제 총비용은 속도 등급, 캐시 적중, 도구 호출 빈도에 따라 달라진다. 구매팀과 플랫폼팀은 구독형 기능과 API형 기능을 나눠 비교할 필요가 있다. 캐시 유지 시간, 추가 요금, 지역별 제공 여부는 계약 전에 확인해야 한다.

검토할 질문도 분명하다.

  • 사내 문서와 업무 시스템을 ChatGPT Space나 plugins에 연결해도 되는가.
  • 에이전트가 실행한 작업 기록을 감사 추적용으로 남길 수 있는가.
  • AWS 안 실행과 OpenAI 직접 사용 중 어느 쪽이 규제 대응에 유리한가.
  • Pro, Business, Enterprise별 기능 차이가 현업 배포에 어떤 제약을 주는가.

아직 비어 있는 정보도 있다. OpenClaw enterprise harness는 행사에서 잠깐만 언급됐다. Dots의 세부 조건도 문서가 충분하지 않다는 커뮤니티 반응이 있었다. 성능 수치 다수는 OpenAI 자체 측정이라, 사내 파일럿으로 지연과 정확도를 다시 재야 한다.
