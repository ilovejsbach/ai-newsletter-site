OpenAI, GPT-6.1 Sol을 Astra의 5분의 1 가격에 공급

GPT-6.1 Sol은 최고 성능 모델인 Astra를 그대로 대체하려는 제품은 아니다. OpenAI는 성능을 조금 낮추는 대신 가격을 크게 낮춰, 실제 업무에서 더 자주 쓰게 하려는 모델로 소개했다. 특히 코딩, 복잡한 PDF 이해, 다단계 업무 자동화처럼 기업 현장에서 많이 쓰는 과제를 전면에 내세웠다. 비용과 성능을 함께 봐야 하는 팀에게는 이 비교가 더 중요하다.

핵심 브리핑

GPT-6.1 Sol은 코딩과 문서 이해, 업무 자동화 평가에서 Astra에 가까운 성능을 더 낮은 비용으로 노린 모델이다. 최고 성능보다 운영 단가가 더 민감한 팀을 겨냥했다.

OpenAI는 GPT-6.1 Sol을 GPT-6 Sol의 업그레이드로 공개했다. 회사는 이 모델이 에이전트형 코딩, 컴퓨터 사용, 전문 업무에서 GPT-6 Astra에 거의 맞먹는다고 밝혔다. 표준 API 가격은 Astra의 입력과 출력 단가 대비 5분의 1이다. 캐시 입력Cached input — 이전에 보낸 문맥을 재사용할 때 더 낮게 책정한 입력 비용 가격은 100만 토큰Token — 모델이 처리하는 글자 조각 단위당 0.10달러다. OpenAI는 이 가격이 표준 입력 대비 95% 낮고, 기존 GPT-6 Sol의 캐시 입력보다 50% 낮다고 설명했다.

  • GPT-6 Astra: 입력 100만 토큰당 10.00달러, 출력 100만 토큰당 50.00달러, 캐시 입력 100만 토큰당 1.00달러
  • GPT-6.1 Sol: 입력 100만 토큰당 2.00달러, 출력 100만 토큰당 10.00달러, 캐시 입력 100만 토큰당 0.10달러
  • GPT-6 Luna: 입력 100만 토큰당 0.10달러, 출력 100만 토큰당 0.50달러, 캐시 입력 100만 토큰당 0.01달러
  • 제공 범위: ChatGPT Work, Codex, OpenAI API
  • 제공 대상: Plus, Pro, Business, Enterprise, Edu 사용자
  • 제한: Chat에서는 아직 미제공
  • 예고: Codex에 표준 속도 대비 최대 8배 빠른 GPT-6.1 Sol Ultrafast를 며칠 안에 추가 예정

주요 트렌드

이번 발표의 핵심은 최고 성능 경쟁보다 가격 구간 세분화다. OpenAI는 Astra를 최상단에 두고, Sol을 중간 가격대 주력 모델로 밀고 있다. Luna는 대량 처리용 저가 모델로 배치했다.

기업 입장에서는 우열이 더 분명해졌다. 가장 어려운 연구 과제는 Astra가 앞선다. 반면 코딩, 문서 질의, 업무 자동화처럼 호출량이 큰 구간은 Sol이 더 싸다. OpenAI는 같은 행사에서 ChatGPT와 API, Codex를 함께 묶고 있어, 모델 판매보다 작업 흐름 전체를 묶는 전략을 강화하는 모습이다.

업계의 움직임

여러 매체가 이 소식을 함께 다뤘다. 제공된 발췌에는 고객사 도입 사례는 없다. 경쟁 모델 비교는 공개 보고서 수치를 가져왔다고 OpenAI가 밝혔다. AutomationBench에서는 Claude Fable 5.1의 비용이 실제보다 낮게 잡혔다고도 덧붙였다. 약 40% 과제에서 폴백 비용이 빠졌기 때문이다.

시사점과 체크포인트

금융IT 조직은 문서 처리와 내부 자동화 과제부터 검토할 만하다. 발췌에 나온 GDP.pdf는 금융을 포함한 전문 문서 과제를 쓴다. 복잡한 PDF를 읽고 답하는 업무는 실제 현업 수요와 맞닿아 있다.

확인할 질문도 분명하다.

  • 우리 업무는 최고 성능이 필요한가, 아니면 Sol급 비용 구조가 더 맞는가
  • 캐시 입력을 살릴 만큼 같은 문맥을 반복 호출하는가
  • 코딩 보조, 문서 질의, 업무 자동화 중 어디서 비용 절감 효과가 큰가
  • Chat과 API, Codex 중 어느 배포 경로가 부서별로 맞는가

성능 수치는 대부분 OpenAI 연구 환경이나 API에서 측정했다. 실제 ChatGPT 제품과는 시스템 프롬프트, 도구, 설정 차이로 출력이 조금 다를 수 있다. 경쟁사 수치는 공개 보고서를 인용했으므로, 구매 판단 전에는 같은 업무 데이터로 재검증이 필요하다.

벤치마크Benchmark — 정해진 과제로 모델 성능을 비교하는 평가 해석도 주의해야 한다. 사실성 평가는 사용자가 오류를 지적한 어려운 대화만 따로 모아 측정했다. 일반 사용 환경을 그대로 대표하지는 않는다. 과학 연구 과제에서는 Astra가 68.1%로 가장 높은 점수를 유지했다. 가장 어려운 연구 업무는 여전히 Astra 쪽이 낫다.
