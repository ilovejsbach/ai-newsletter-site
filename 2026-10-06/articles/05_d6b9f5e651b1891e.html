OpenAI, GPT-6.1 Sol 가격 인하

OpenAI가 새 모델 GPT-6.1 Sol을 공개했다. 이 모델은 코딩과 컴퓨터 조작, 전문 지식 업무를 겨냥한다. 핵심은 성능보다 가격 포지션이다. OpenAI는 Astra에 가까운 성능을 더 낮은 API 비용으로 제공한다고 설명했다.

핵심 브리핑

GPT-6.1 Sol은 코딩, 컴퓨터 사용, 전문 업무를 겨냥한 모델이다. OpenAI는 이 모델이 AstraOpenAI가 비교 기준으로 언급한 상위 모델에 가까운 지능을 제공한다고 밝혔다. 동시에 APIApplication Programming Interface — 다른 프로그램이 모델을 호출하는 연결 규칙 기준 입력 토큰Token — 모델이 텍스트를 처리할 때 쓰는 최소 단위과 출력 토큰Output token — 모델이 답변으로 생성한 텍스트 분량 가격은 Astra 표준가의 5분의 1이라고 설명했다.

이번 공개로 사용 기업이 먼저 따질 지점도 분명하다. 같은 작업량이라면 Astra보다 비용을 낮출 수 있다는 뜻이다. 반대로 실제 품질 차이는 업무 종류별 검증이 필요하다. 현재 제공된 발췌에는 정확한 가격표와 벤치마크 수치, 배포 조건은 없다.

맥락 읽기

이번 소식의 초점은 최고 성능 경쟁보다 가격 대비 성능이다. OpenAI가 비교 대상을 자사 상위 모델 Astra로 잡았다는 점도 눈에 띈다. 여러 매체가 함께 다룬 사건이라, 시장은 새 모델을 독립 제품이라기보다 상위 모델의 저가형 선택지로 읽고 있다.

비개발 부서 기준으로 보면 의미는 단순하다. 같은 예산에서 더 많은 문서 작업이나 코딩 보조 호출을 시도할 수 있다. 다만 금융 업무처럼 오류 비용이 큰 구간에서는 단가보다 정확도와 통제 기능을 먼저 확인해야 한다.
