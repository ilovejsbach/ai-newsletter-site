OpenAI API에 Ultrafast 모드가 먼저 붙는다

Cerebras와 OpenAI가 OpenAI API용 Ultrafast Mode를 공개했다. 이 티어는 먼저 일부 고객에게 제한적으로 열린다. Cerebras는 GPT-5.6 Sol이 이 모드에서 높은 품질을 유지한 채 매우 빠르게 응답한다고 설명했다. 핵심 메시지는 프런티어급 모델에서도 속도와 성능을 함께 잡겠다는 것이다.

핵심 브리핑

Ultrafast Mode는 OpenAI API에서 먼저 시작하는 새 서비스 티어다. Cerebras가 이 모드의 인프라를 맡는다. 초기에는 일부 고객만 쓸 수 있고, 접근 범위는 점차 넓힐 계획이다.

  • 최대 출력 속도: up to 750 output tokens per second
  • Fable 5 대비 속도: 11x faster
  • Opus 4.8 Fast mode 대비 속도: 5x faster
  • HLE 문제 수: 2,500
  • GPT-5.6 Sol Ultrafast HLE 완료 시간: 11 hours and 11 minutes
  • Claude Fable 5 HLE 완료 시간: 78 hours and 27 minutes
  • GDP-Val 종단 속도 향상: 5.6x

Cerebras는 GPT-5.6 Sol Ultrafast가 HLE에서 2,500문항을 11시간 11분에 풀었다고 밝혔다. 같은 비교에서 Claude Fable 5는 78시간 27분이 걸렸다고 적었다. GDP-Val에서도 품질 저하 없이 종단 처리 시간을 줄였다고 설명했다.

Cerebras는 이 모드를 법률 문서, 금융 모델, 엔지니어링 보고서 같은 고부가가치 지식 업무에 맞춘다고 강조했다. 웹 서비스 장애 분석, 보안 사고 대응처럼 시간이 중요한 운영 업무도 주요 사례로 제시했다.

주요 트렌드

이 발표의 핵심은 새 모델이 아니라 새 속도 티어다. 모델 경쟁이 성능 점수에서 응답 시간과 처리량 경쟁으로 넓어지고 있다. 같은 모델이라도 어떤 인프라 위에서 어떤 티어로 서비스하느냐가 차별점이 된다.

사업 구조도 바뀐다. OpenAI는 API 전면을 맡고, Cerebras는 초고속 추론 인프라를 맡는다. 모델 회사와 칩 회사가 함께 상품을 만드는 방식이다. 고객은 모델 이름만 보는 대신 서비스 티어, 속도, 가용성도 같이 봐야 한다.

속도 수치가 전면에 나온 점도 눈에 띈다. 이제 경쟁 포인트는 정확도만이 아니다. 시간이 직접 비용과 손실에 연결되는 업무에서는 지연 시간이 계약 조건이 될 수 있다.

업계의 움직임

OpenAI News, Reddit r/LocalLLaMA, Simon Willison Blog 등 여러 채널이 같은 사건을 함께 다뤘다. 커뮤니티 관심은 새 모델 자체보다 Ultrafast 모드의 실제 속도와 OpenAI API 적용 범위에 모였다. 관련 보도에는 GPT-5.6 Sol의 큰 컨텍스트 윈도우 설정을 다룬 기사도 함께 묶여 나왔다.

시사점과 체크포인트

우리 회사가 실시간성이 필요한 AI 업무를 검토한다면, 성능 평가표와 함께 응답 시간 목표를 먼저 정해야 한다. 보안 관제, 장애 대응, 시장·리스크 요약처럼 분 단위 판단이 필요한 곳은 초고속 추론의 효과가 크다.

체크포인트는 다음과 같다.

  • 검토 팀: 보안관제, SRE, IT운영, 리스크관리, 리서치 자동화
  • 확인 질문: Ultrafast 모드의 가격, 지역 가용성, 데이터 보관 정책, SLA 제공 범위
  • 기술 질문: 기존 API와 호출 방식이 같은지, 속도 향상 시 도구 호출과 장문 추론 품질이 유지되는지
  • 운영 질문: 일부 고객 제한이 언제 풀리는지, 장애 시 표준 티어로 자동 전환할 수 있는지

이번 글에는 가격이 없다. 실제 도입 판단에는 비용 정보가 빠져 있다. 벤치마크도 Cerebras가 수행한 수치라서, 우리 업무 데이터로 별도 검증이 필요하다.

주요 용어

추론(Inference): 학습된 모델이 입력을 받아 답을 생성하는 과정 서비스 티어(Service tier): 같은 서비스 안에서 성능이나 조건을 나눈 이용 구간 SRAM(Static Random-Access Memory): 칩 안에 붙는 고속 메모리 메모리 대역폭(Memory bandwidth): 메모리와 연산 장치 사이에서 데이터를 옮기는 속도 HLE(Humanity's Last Exam): 고난도 지식 문제 2,500개로 구성된 모델 평가
