저렴하게 붙이는 경량 음성 합성

apache-2.0 사내 사용 가능갱신일 04.10

음성 합성 모델은 안내 멘트, 콘텐츠 읽기, 상담 보조에 자주 들어간다. 실무에서는 자연스러운 소리만큼 비용과 반입 조건이 중요하다. Kokoro-82M은 큰 모델보다 가볍게 쓰는 자리를 노린 공개형 모델이다.

무엇을 하는 모델인가

Kokoro-82M은 글을 입력하면 음성을 내보내는 모델이다. 안내 문구나 읽기 콘텐츠를 소리로 바꿀 때 쓴다. 이 모델이 없으면 사람이 직접 녹음하거나 외부 음성 APIApplication Programming Interface — 다른 프로그램이 모델을 호출하는 연결 규칙를 불러야 한다. 만든 쪽은 큰 모델에 견줄 만한 품질을 내면서 더 빠르고 비용도 낮다고 밝혔다.

성능과 한계

만든 쪽은 더 큰 모델에 견줄 만한 품질을 내면서 더 빠르고 비용도 낮다고 밝혔다. 2025년 4월 기준 API 시세는 입력 100만 글자당 1달러 미만이거나 출력 오디오 1시간당 0.06달러 미만이라고 적었다. 이 수치는 ArtificialAnalysis·Replicate와 DeepInfra 가격을 함께 적은 값이다. 벤치마크 평가는 공개되지 않았다.

언제 이것을 고르나

상업 서비스에 바로 넣어야 하면 Kokoro-82M이나 Qwen/Qwen3-TTSText-to-Speech — 글을 사람 목소리 같은 음성으로 바꾸는 기술-12Hz-1.7B-CustomVoice 쪽이 먼저 검토 대상이다. 둘 다 Apache-2.0이다. 작은 모델을 우선 보고 싶으면 Kokoro-82M이 맞다. 반대로 언어 수와 음성 제어 기능을 더 보려면 Qwen 쪽이 낫다.
