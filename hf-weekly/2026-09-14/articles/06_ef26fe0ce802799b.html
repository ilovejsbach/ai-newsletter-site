06 Hugging Face

화면 초안을 만드는 생성형 UI 모델

apache-2.0 사내 사용 가능공개일 09.11

이번 주 모델 가운데 OUI-1은 업무 자동화보다 화면 생성 쪽에 가깝다. 금융IT 현장에서는 운영 배치보다 시안 제작과 실험이 먼저 떠오르는 유형이다. 카드 정보가 매우 짧아서, 쓸 수 있는 범위와 비어 있는 항목을 함께 봐야 한다.

무엇이 나왔나

thesysdev/OUI-1은 생성형 UI용 모델이다. thesysdev가 공개했고, base model로 google/diffusiongemma-26B-A4B-it를 적었다. Apache-2.0이라 상업 이용 제약은 없다.

눈에 띄는 점

카드는 이 모델을 diffusion-language-model과 generative-ui로 분류했다. 일반 챗봇이 아니라 화면 생성에 초점을 둔다는 뜻이다. base model을 밝히고 파인튜닝 관계도 함께 적어, 계보는 비교적 분명하다.

지금 쓸 수 있나

상업 이용은 가능하다. 접근 승인 필요 여부는 카드에 보이지 않는다. 파라미터 수와 필요한 장비는 카드가 밝히지 않았다. 실행 예제도 없어, 바로 사내 서버에서 검증하려면 추가 확인이 먼저다.

주요 용어

생성형 UI(Generative UI): 화면 구성 요소와 배치를 모델이 만들어 내는 방식 파인튜닝(Fine-tuning): 기존 모델을 특정 용도에 맞게 추가 학습하는 일 엔드포인트 호환(Endpoints compatible): 호스팅 호출 방식에 맞춰 쓸 수 있다는 뜻
