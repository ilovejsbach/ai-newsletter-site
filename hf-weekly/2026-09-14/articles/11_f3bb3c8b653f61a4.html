11 Hugging Face

코드 원문과 문제형 데이터를 함께 묶은 세트

apache-2.0 사내 사용 가능공개일 09.07

데이터셋 기사는 모델만큼 직접 쓰기 쉽지 않다. 그래도 사내 학습팀에는 데이터 구조와 반입 조건이 더 중요할 때가 있다. UltraData-Code는 코드 원문과 합성 과제 데이터를 단계별로 나눠 공개한 사례다.

무엇이 나왔나

openbmb/UltraData-Code는 코드 학습용 데이터셋이다. OpenBMB가 공개했고, 공개 GitHub 저장소 약 1억 9200만 개를 출발점으로 삼았다. 이번 공개분은 11개 프로그래밍 언어의 L2와 L3다.

눈에 띄는 점

이번 공개는 선별 코드와 과제형 합성 코드를 함께 내놨다. L2는 약 4000억 토큰이고, L3는 약 1500억 토큰이다. 카드에 따르면 10B 토큰 조건의 1B 모델 학습에서 L2는 L1보다 EvalPlus 7.80점, MultiPL-E 5.13점 높았다. L2 절반을 L3로 바꾸면 L2만 쓴 경우보다 8.42점과 8.07점 더 올랐다.

지금 쓸 수 있나

Apache-2.0이라 상업 이용에 제약이 없다. 카드에는 접근 승인 조건이 보이지 않는다. 형식은 parquet이고, 데이터는 텍스트와 표 형식으로 묶였다. 규모가 매우 커서 사내 반입은 전량보다 필요한 레벨과 언어를 먼저 고르는 편이 현실적이다.

주요 용어

데이터셋(Dataset): 모델 학습이나 평가에 쓰는 정리된 자료 모음. 토큰(Token): 모델이 텍스트를 쪼개 읽는 최소 단위. 지속 사전학습(Continual pre-training): 기존 모델을 추가 데이터로 더 학습하는 과정. EvalPlus: 코드 생성 정답률을 재는 벤치마크. MultiPL-E: 여러 프로그래밍 언어의 코드 생성 성능을 재는 벤치마크. Parquet: 대용량 표 형식 데이터를 저장하는 파일 형식.
