heygen-com/hyperframes

HTML 문서만 적으면 영상이 나오는 렌더링 도구

★ 58,669이번 주 +4,410TypeScriptApache-2.0 사내 사용 가능릴리스 v0.8.140 (10.07)최근 활동 10.08테스트 없음예제 있음AGENTS.md 있음

HyperFrames는 HTML 문서로 장면을 적고 영상 파일로 뽑는 오픈소스 렌더링 엔진이다. 저장소를 올린 HeyGen은 명령줄 도구, 재사용 블록 카탈로그, 브라우저 편집 화면인 스튜디오, AWS Lambda 렌더링을 한 묶음으로 내놓았다. 만든 쪽은 이 도구를 HeyGen의 실제 서비스에 쓰고 있다고 밝혔다. 최신 릴리스는 10월 7일에 나온 v0.8.140이다.

무엇을 하는 물건인가

heygen-com/hyperframes는 HTML 문서에 장면을 적으면 영상 파일로 만들어 주는 도구다. 연주 악보에 음마다 시작 시점과 길이를 적듯, 화면 요소와 소리의 시작 시점과 길이를 문서 안에 적는다. 이 도구가 없으면 영상 편집 프로그램을 열어 장면마다 요소를 손으로 놓고 맞춘 뒤 내보내야 한다.

스펙과 도입 조건

  • 언어: TypeScript로 만들었고, 영상 장면은 HTML 파일로 적는다.
  • 설치 형태: 명령줄 도구와 용도별 패키지로 나뉜다. 미리보기 화면, 웹 플레이어, 전환 효과, AWS Lambda 연동 패키지가 따로 있다.
  • 실행 환경: 로컬이나 Docker에서 렌더링Rendering — 화면 구성 정보를 실제 영상이나 이미지 파일로 만들어 내는 작업한다고 적혀 있다. 헤드리스 Chrome으로 프레임을 찍고 FFmpeg(영상 변환 도구)로 영상과 소리를 합친다. AWS Lambda에서 분산 렌더링도 할 수 있다.
  • 의존 서비스: 외부 API 키가 필요한지는 밝혀져 있지 않다.
  • 라이선스: Apache 2.0이며, 렌더링당 요금이나 상업 이용 기준은 없다고 적혀 있다.
  • 성숙도: 최신 릴리스는 v0.8.140(2026년 10월 7일)이다. 스튜디오 편집 화면은 발전 중인 상태로 표시돼 있다.

이럴 때 쓰면 좋다

  • 월말 금리나 수수료 변경 안내처럼 형식이 같고 숫자만 바뀌는 고객 안내 영상을, 문서 하나로 매달 자동 렌더링할 때 쓴다.
  • 신입 보안 교육 영상에 애니메이션 차트와 자막 블록을 넣고, 규정이 바뀌면 문서만 고쳐 개정판을 다시 뽑을 때 쓴다.
  • AI 에이전트AI agent — 목표를 받으면 도구를 써 가며 스스로 작업을 처리하는 AI 프로그램에게 공지 문구를 주고 HTML 영상 초안을 만들게 하는 사내 시험에 쓴다.

핵심 기능

  • 빌드 단계 없이 index.html을 브라우저에서 바로 재생하고 미리 볼 수 있다.
  • 프레임을 하나씩 찍어 영상으로 묶는 결정적 렌더링Deterministic rendering — 같은 입력에서 항상 같은 결과물이 나오는 렌더링 방식이라, 같은 입력이면 같은 영상이 나온다. 자동 렌더링과 회귀 테스트에 쓸 수 있다고 적혀 있다.
  • 카탈로그에서 전환 효과, 소셜 오버레이, 자막, 차트, 지도 블록을 골라 설치하고, GSAP, Lottie, Three.js 같은 애니메이션 도구를 어댑터로 연결한다.

왜 지금 주목받나

HyperFrames는 HTML 문서에 장면을 적으면 영상이 나오는 도구라서, AI 에이전트에게 영상 제작을 맡기기 쉽다. 만든 쪽은 에이전트가 이미 HTML을 쓰고 있고, 명령줄 도구도 기본적으로 사람의 입력 없이 돌아간다고 설명한다. 비교 대상인 Remotion도 Chrome과 FFmpeg로 영상을 만들지만, 장면은 React 컴포넌트로 작성한다.

만든 쪽이 정리한 아래 표에서 HyperFrames는 빌드 단계가 없고 Remotion은 번들러가 필요하다. 반대로 클라우드 분산 렌더링은 Remotion Lambda를 성숙한 렌더러로 적어, 이 영역은 Remotion이 앞선다는 것이 만든 쪽 평가다.

10월 7일에 나온 v0.8.140은 영상 위에서도 모션 블러가 동작하고, 렌더링 중 인코딩Encoding — 프레임을 모아 재생 가능한 영상 파일 형식으로 압축·변환하는 작업과 조립 진행 상황을 보여 준다. 스튜디오 미리보기와 이미지 교체, 긴 타임라인 확대도 안정화됐다고 릴리스 노트에 적혀 있다. 도입 사례 목록에는 tldraw, TanStack 같은 팀의 예시가 올라 있다.

사내 도입 체크

  • 외부 API 호출: 렌더링은 로컬이나 Docker에서 돌린다고 적혀 있다. 카탈로그 내려받기나 음악 요청 같은 기능이 외부 서비스에 접속하는지는 확인 필요.
  • 데이터 반출: AWS Lambda 분산 렌더링은 영상 소재가 클라우드로 올라가므로 사내 반출 기준을 확인해야 한다.
  • 유지보수 주체: 저장소를 올린 HeyGen이 서비스에 쓰고 있고, Discord와 이슈 게시판, 보안 신고 창구를 운영한다. 버전이 0.8대라 1.0 이전이다.
  • 상용 대체 제품: 비교 대상인 Remotion은 소스 공개형 라이선스라고 표에 적혀 있다. 다른 상용 영상 제작 제품과의 비교는 확인 필요.
