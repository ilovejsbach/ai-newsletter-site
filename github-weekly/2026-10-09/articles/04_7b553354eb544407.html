이 저장소는 선형대수에서 시작해 자율 에이전트와 여러 에이전트의 협업까지 다루는 AI 개발 커리큘럼이다. 만든 쪽은 523개 레슨, 20단계, 약 342시간 분량이라고 밝혔다. 레슨 코드는 Python, TypeScript, Rust, Julia 네 언어로 제공한다. 후원으로 무료 공개를 유지한다고 적혀 있으며, 개인 노트북에서 돌아가게 만들었다고 한다.

무엇을 하는 물건인가

rohitg00/ai-engineering-from-scratch는 AI 개발을 수학 기초부터 에이전트까지 직접 코드를 짜며 배우는 무료 강의 자료 모음이다. 계산기를 쓰기 전에 손으로 계산해 보고, 그다음 계산기로 같은 계산을 맞춰 보는 식으로 진행한다. 이 자료가 없으면 논문 한 편, 모델 조정 글 하나, 에이전트 시연 하나처럼 흩어진 자료를 직접 찾아 순서를 짜 맞춰야 한다.

스펙과 도입 조건

  • 언어: 저장소의 주 언어는 Python이고, 레슨 코드는 Python, TypeScript, Rust, Julia로 제공한다.
  • 설치 형태: 저장소를 내려받아 레슨 명령을 실행하거나 웹사이트에서 읽을 수 있다. 터미널 학습에는 Node.js, npx, 스킬을 지원하는 코딩 에이전트가 필요하고, 실습 코드에는 python3가 필요하다고 적혀 있다.
  • 의존 서비스: 외부 API 키가 필요한지는 밝혀져 있지 않다. 개인 노트북에서 돌아가게 만들었다고 한다.
  • 라이선스: MIT이며 무료 오픈소스다.
  • 성숙도: 최신 릴리스는 v2026.10.1(2026년 10월 6일)이다. 날짜를 버전 번호로 쓴다.

이럴 때 쓰면 좋다

  • 신입 개발자 온보딩에서 AI 기초 단계부터 순서대로 따라가는 사내 스터디 커리큘럼으로 쓴다.
  • 배치 퀴즈Placement quiz — 현재 실력에 맞는 시작 단계를 정해 주는 문제 모음로 시작 단계를 정해, 직원마다 실력에 맞는 학습 계획을 세울 때 쓴다.
  • 사내 챗봇 개발팀이 MCPModel Context Protocol — AI가 외부 도구와 데이터에 접속할 때 쓰는 공통 규격 17개 레슨 경로나 에이전트 스킬Agent Skills — 코딩 에이전트에게 특정 작업 방법을 알려 주는 설명 파일 묶음 5개 레슨 경로만 골라 짧게 익힐 때 쓴다.

핵심 기능

  • 모든 레슨이 문제 제시, 개념 설명, 원리부터 직접 구현, 실제 라이브러리Library — 자주 쓰는 기능을 미리 만들어 모아 둔 코드 묶음로 재현, 결과물 보관 순서로 같은 구조를 따른다.
  • 레슨마다 프롬프트, 스킬, 에이전트, MCP 서버 중 재사용할 수 있는 결과물을 남긴다.
  • 터미널에서 학습용 스킬을 설치하면 10문항 배치 퀴즈로 시작 단계를 정하고, 학습 계획을 파일로 저장한다. 이후 한 번에 레슨 하나씩 진행한다.

왜 지금 주목받나

이 저장소는 수학 기초부터 자율 에이전트까지 한 순서로 묶은 AI 개발 강의로, 알고리즘을 직접 만든 뒤 실제 라이브러리로 같은 일을 해 보게 한다. 만든 쪽은 AI 자료가 논문, 모델 조정 글, 에이전트 시연으로 흩어져 서로 잘 맞지 않는다고 지적한다. 5분짜리 영상, 복사해 붙이는 배포, 손잡고 안내하는 방식은 쓰지 않는다고 소개 글에 적혀 있다.

소개 글에는 학생 84%가 이미 AI 도구를 쓰지만 업무에 쓸 준비가 됐다고 느끼는 비율은 18%라고 적혀 있고, 출처는 밝혀져 있지 않다. 만든 쪽은 이 강의가 그 격차를 줄인다고 주장한다. 터미널 학습을 고르면 명령 두 개로 학습용 스킬을 설치해 코딩 에이전트를 튜터로 쓸 수 있고, 만든 쪽은 30초면 된다고 소개한다. 단, Node.js와 npx, 스킬을 지원하는 코딩 에이전트가 먼저 깔려 있어야 한다.

사내 도입 체크

  • 외부 API 호출: 레슨 실습이 외부 API를 부르는지는 확인 필요.
  • 데이터 반출: 학습용 스킬이 레슨을 저장소에서 바로 내려받는 방식이라, 사내망에서 접속을 허용할 수 있는지는 확인 필요.
  • 유지보수 주체: 개인 계정(rohitg00)이 운영하며, 후원으로 무료 공개를 유지한다고 적혀 있다.
  • 상용 대체 제품: 사내 시스템에 넣는 소프트웨어가 아니라 학습 자료이므로 비교 대상은 상용 교육 서비스다. 어느 서비스와 견줄지는 확인 필요.
