기능을 플러그인으로 붙이는 에이전트 도구

에이전트 도구 시장은 기능을 한 제품 안에 많이 넣는 쪽과, 필요한 기능만 골라 붙이는 쪽으로 갈린다. DeepSeek Harness는 후자를 분명하게 내세운다. 저장소 설명은 모든 것을 플러그인으로 본다고 적었다. 대신 아직은 개발자 미리보기 단계라고 못 박았다.

무엇을 하는 물건인가

DeepSeek Harness는 기능을 플러그인으로 붙여 쓰는 에이전트 도구다. 웹 화면을 로컬에서 띄워 실행할 수 있다. 이 도구가 없으면 필요한 기능을 한 덩어리 제품이 정한 방식대로 써야 하거나, 각 기능을 직접 이어 붙여야 한다. 필요한 부품을 꽂아 쓰는 멀티탭처럼 쓰임새를 넓히는 방향에 가깝다.

스펙과 도입 조건

  • 언어는 TypeScript다.
  • npm으로 실행할 수 있다.
  • 소스에서 돌릴 때는 pnpm 설치와 빌드가 필요하다.
  • 로컬 실행에는 Node.js가 필요하다.
  • 기본 웹 화면은 127.0.0.1:3080에서 열린다.
  • 라이선스는 MIT다.
  • 정식 릴리스는 아직 없다.
  • 개발자 미리보기 단계이며 호환성 깨짐이 생길 수 있다고 밝혔다.

이럴 때 쓰면 좋다

  • 고객 문의 분류 보조 도구를 붙였다 뗐다 하며 어떤 기능 조합이 맞는지 소규모로 검증할 때 쓸 수 있다.
  • 규정 문서 검색 화면을 로컬 PC에서 먼저 띄워 보고 보안 검토 전 단계의 실험을 할 때 어울린다.
  • 내부 자동화 아이디어를 플러그인 단위로 나눠 팀별로 시험하려는 연구 성격의 프로젝트에 맞다.

핵심 기능

  • 모든 기능을 플러그인으로 다루는 구조를 채택했다.
  • 웹 화면을 로컬에서 실행할 수 있다.
  • 문서 사이트와 개발 가이드, 구조 문서를 별도로 제공한다.

왜 지금 주목받나

이 저장소는 기능 확장을 제품 내부 옵션이 아니라 플러그인 구조로 밀어붙인다. 기능을 잘게 나눠 시험하려는 팀에는 매력적일 수 있다. 반면 만든 쪽은 빠르게 바뀌고 호환성 깨짐이 생긴다고 분명히 적었다. 실무 도입보다 구조 검토와 실험용 검증이 먼저인 도구다.

사내 도입 체크

  • 외부 API 호출 여부는 확인 필요다.
  • 기본 웹 화면은 로컬에서 열리지만 데이터 반출 가능성은 확인 필요다.
  • 유지보수 주체는 DeepSeek AI라는 조직이다.
  • 플러그인 구조를 앞세운 다른 에이전트 도구가 있어 대체 제품은 있다.

주요 용어

플러그인(Plugin): 필요한 기능을 덧붙이는 추가 구성요소 개발자 미리보기(Developer Preview): 정식 출시 전 시험 단계 호환성 깨짐(Compatibility-breaking change): 기존 설정이나 코드가 그대로는 동작하지 않게 되는 변경 Web UI: 웹 브라우저에서 쓰는 화면 Cordis: 이 저장소가 기반으로 삼는 소프트웨어 구조 이름
