Claude Code 운영법을 모은 실전 참고서

★ 66,246이번 주 +297HTMLMIT 사내 사용 가능최근 활동 09.22테스트 없음예제 없음AGENTS.md 없음

이 저장소는 도구 자체보다 사용법과 운영 습관을 모아 둔 자료다. 만든 쪽은 이를 과정형 참고서로 읽으라고 적었다. Claude Code의 명령, 에이전트, 스킬, 훅을 어떻게 조합할지 예시와 질문 목록으로 정리했다. 다른 모델과 함께 쓰는 방법도 플러그인, MCP, 라우터 세 갈래로 나눠 설명한다.

무엇을 하는 물건인가

이 저장소는 Claude Code를 더 체계적으로 쓰기 위한 사용 지침 모음이다. 어떤 일을 명령으로 만들고, 어떤 일은 에이전트나 스킬로 나눌지 예시와 파일 위치를 함께 보여 준다. 이 자료가 없으면 팀은 각자 프롬프트를 따로 적어 보며 좋은 사용법을 시행착오로 찾아야 한다. 업무 매뉴얼과 체크리스트를 한 권으로 모아 둔 사내 핸드북에 가깝다.

스펙과 도입 조건

  • 주 언어 표기는 HTML이다.
  • 별도 설치 패키지나 실행 파일은 밝혀져 있지 않다.
  • 외부 API 키 필요 여부는 밝혀져 있지 않다.
  • 라이선스는 MIT다.
  • 릴리스는 없다.

이럴 때 쓰면 좋다

  • 사내 개발팀이 고객 문의 분류나 코드 수정 요청을 Claude Code에 맡길 때 공통 작업 절차를 정리하려는 경우에 맞다.
  • 여러 AI 도구를 함께 쓰는 팀이 두 개 터미널로 계획과 검토를 나눠 운영하는 방식을 시험할 때 참고할 수 있다.
  • 규정 문서나 프로젝트 규칙을 CLAUDE.md 같은 파일에 어떻게 적을지 기준이 필요할 때 유용하다.

핵심 기능

  • Research → Plan → Execute → Review → Ship 흐름으로 주요 개발 작업 순서를 정리했다.
  • Claude Code와 다른 모델을 플러그인, MCP, 라우터 방식으로 함께 쓰는 방법을 모았다.
  • 에이전트, 명령, 스킬, 훅, 설정 파일의 위치와 역할을 표로 정리했다.

대안 대비 차별점

일반 사용 팁 모음과 달리 이 저장소는 명령, 에이전트, 스킬을 어떻게 나눌지 구조부터 보여 준다. /weather-orchestrator 예시로 command → agent → skill 흐름을 실제 형태로 제시한 점이 눈에 띈다. 다른 모델을 Claude Code 안에 붙이는 방법도 플러그인, MCP, 라우터로 구분해 정리했다. 새 프로그램을 설치하는 저장소가 아니라 팀 운영 규칙과 실무 패턴을 모은 참고서라는 점이 가장 큰 차이다.

사내 도입 체크

  • 외부 API 호출 여부는 확인 필요다. 이 저장소는 사용법 자료라 자체 호출 기능은 없다.
  • 데이터 반출 가능성은 실제로 연결할 Claude Code와 다른 모델 설정에 따라 달라진다. 확인 필요다.
  • 유지보수 주체는 개인 계정이다.
  • 상용 대체재는 있다. 다만 이 저장소는 상용 제품이 아니라 공개된 운영 팁과 예시 모음이다.

주요 용어

에이전트(Agent): 주어진 목표를 여러 단계로 처리하는 AI 작업 단위 스킬(Skill): 특정 작업을 반복 실행하도록 정리한 재사용 지침 훅(Hook): 특정 시점에 자동으로 실행되는 연결 규칙 MCP(Model Context Protocol): 모델에 외부 도구를 붙이는 연결 규칙 컨텍스트 윈도(Context Window): 모델이 한 번에 참고할 수 있는 입력 범위
