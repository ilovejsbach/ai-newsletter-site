Supabase는 Postgres 기반 개발 플랫폼으로 소개된다. 데이터베이스, 인증, 자동 생성 API, 함수, 파일 저장소, AI·벡터 도구, 대시보드를 한 묶음으로 제공한다. 호스팅형으로 바로 시작할 수 있고, 자체 구축과 로컬 개발도 가능하다. 이번 달 소식으로는 Pipelines 공개 알파, Unified Logs 공개 베타, Grafana Cloud 연동, Supabase Evals 공개 등을 알렸다.

무엇을 하는 물건인가

Supabase는 데이터베이스와 로그인, 파일 저장소, API를 한 번에 제공하는 플랫폼이다. 웹이나 모바일 서비스, AI 기능을 붙일 때 필요한 기본 부품을 Postgres 중심으로 묶어 둔다. 이 도구가 없으면 팀은 데이터베이스와 인증, 파일 저장소, 실시간 기능을 각각 골라 따로 연결해야 한다. 새 지점을 열 때 금고와 출입카드, 창구 시스템을 따로 들여오는 대신 한 패키지로 받는 느낌에 가깝다.

스펙과 도입 조건

  • TypeScript 중심 저장소다.
  • 호스팅형으로 바로 시작할 수 있고, 자체 구축과 로컬 개발도 지원한다.
  • 외부 API 키 필요 여부는 밝혀져 있지 않다.
  • 라이선스는 Apache-2.0이다.
  • 최신 릴리스는 v1.26.08이다.
  • 예제와 AGENTS.md가 포함돼 있다.

대안 대비 차별점

Supabase는 단일 데이터베이스 서비스가 아니라 인증, API, 실시간 구독, 파일 저장소까지 Postgres 중심으로 묶는다. 호스팅형으로 바로 시작할 수 있으면서 자체 구축도 지원해 선택 폭이 넓다. 오픈소스 도구를 우선 조합하고, 없는 부분은 직접 만들어 공개하는 방식을 명시한 점도 특징이다. AI와 벡터 기능을 기본 항목으로 내세워 일반 업무 앱과 검색형 AI 기능을 같은 기반 위에 올리기 쉽다.

이럴 때 쓰면 좋다

  • 고객 포털이나 사내 업무 앱에서 회원 로그인과 권한 관리, 파일 업로드를 한 번에 붙여야 할 때 적합하다.
  • 규정 문서 검색이나 상담 이력 검색을 위해 임베딩과 벡터 검색 기능을 데이터베이스와 같이 운용하려는 경우에 맞다.
  • 거래·로그 데이터 변경 내역을 분석 계열 시스템으로 거의 실시간 전송해 모니터링하려는 팀에 유용하다.

핵심 기능

  • 호스팅형 Postgres 데이터베이스를 제공한다.
  • 인증과 권한 관리, REST·GraphQL API, 실시간 구독을 지원한다.
  • 파일 저장소와 함수, AI·벡터·임베딩 도구, 대시보드를 제공한다.

사내 도입 체크

  • 호스팅형으로 쓰면 외부 서비스 사용이 전제된다. 자체 구축 시 외부 호출 범위는 줄일 수 있다.
  • 데이터 반출 가능성은 호스팅형 사용 여부와 Pipelines 같은 연계 기능 설정에 따라 달라진다. 확인 필요다.
  • 유지보수 주체는 Supabase 조직이다.
  • 상용 대체재는 있다. 다만 이 저장소는 Postgres, 인증, 파일 저장소, API, 벡터 기능을 오픈소스 기반으로 함께 제공한다.

주요 용어

Postgres: 오픈소스 관계형 데이터베이스 CDC(Change Data Capture): 데이터 변경 내역을 다른 시스템으로 보내는 방식 벡터(Vector): 문장이나 이미지 의미를 숫자 배열로 바꾼 값 임베딩(Embedding): 텍스트 의미를 벡터로 표현한 값 GraphQL: 필요한 데이터만 골라 요청하는 API 방식 JWT(JSON Web Token): 로그인 상태와 권한을 담는 토큰 형식
