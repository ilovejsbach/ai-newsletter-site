로컬 모델 실행·학습을 한 UI로 묶었다

이 저장소는 로컬 PC에서 AI 모델을 돌리고 추가 학습까지 할 수 있게 묶은 도구다. 데스크톱 앱, 웹 UI, 코드 기반 설치를 모두 지원한다. 만든 쪽은 Windows, Linux, WSL, macOS를 지원하고, NVIDIA·AMD·Intel GPU와 CPU, Vulkan 백엔드를 폭넓게 지원한다고 적었다. 검색, RAG, 에이전트 연결, 데이터셋 구성, 배포 형식 변환까지 범위를 넓게 잡았다.

무엇을 하는 물건인가

이 도구는 로컬 PC에서 AI 모델을 실행하고 학습까지 관리하는 화면과 명령 도구를 함께 제공한다. 여러 모델 파일, 학습 스크립트, API 연결 설정을 따로 만지던 일을 한 작업대로 모아 준다. 이 도구가 없으면 모델 실행, 추가 학습, API 공개, 에이전트 연결을 각각 다른 도구로 나눠 구성해야 한다. 데스크톱 앱, 웹 UI, 코드 방식 중에서 골라 쓸 수 있다.

스펙과 도입 조건

  • 언어는 Python이다.
  • 설치 형태는 네이티브 데스크톱 앱, 웹 UI 설치, Docker 이미지, 코드 기반 설치를 지원한다.
  • Windows, macOS, Linux x64, Linux ARM64, WSL을 지원한다고 적혀 있다.
  • NVIDIA, AMD, Intel GPU와 CPU, Vulkan 백엔드를 지원한다고 밝혔다.
  • 로컬 모델을 OpenAI 호환 API로 제공할 수 있다.
  • 외부 클라우드 제공자나 ChatGPT/Codex 구독 연결도 지원한다고 적혀 있다.
  • 라이선스는 Apache-2.0이다.
  • 최신 릴리스는 v0.1.814-beta다.

이럴 때 쓰면 좋다

  • 규정 문서 검색용 내부 챗봇을 외부 클라우드 없이 로컬 모델과 RAG로 시험할 때 맞다.
  • 개발 지원 조직이 Claude Code나 Codex를 사내 로컬 모델에 연결해 코드 보조 범위를 점검할 때 쓸 수 있다.
  • 데이터팀이 PDF, CSV, DOCX에서 학습 데이터를 만들고 소규모 파인튜닝 결과를 빠르게 비교할 때 유용하다.

핵심 기능

  • 대규모 언어 모델, 확산 모델, 임베딩, 오디오 모델을 실행하고 학습할 수 있다.
  • Claude Code, Codex, MCP 등과 로컬 모델을 연결하고 도구 호출과 코드 실행을 지원한다.
  • PDF, CSV, DOCX 등에서 데이터셋을 만들고, 학습 뒤 GGUF, NVFP4, FP8 같은 형식으로 내보낼 수 있다.

성능과 운영 비용

만든 쪽은 파인튜닝을 2배 더 빠르게 하고 VRAM 사용량을 70% 줄이면서 정확도 손실은 없다고 적었다. 다만 어떤 모델, 배치 크기, 하드웨어에서 잰 값인지는 이 설명에 구체적으로 붙어 있지 않다. 다른 항목으로는 DiffusionGemma 추론 1.8배, Qwen3.6 추론 1.4배에서 2.2배, 임베딩 파인튜닝 약 1.8배에서 3.3배, MoE 학습 12배, VRAM 35% 절감, 새 커널로 학습 3배와 VRAM 30% 절감 수치를 적었다. 이 수치들은 블로그와 가이드로 연결돼 있지만, 여기서는 측정 주체만 만든 쪽이라는 점까지만 확인된다.

운영 쪽에서는 단일 앱으로 넓은 하드웨어를 지원하는 대신 설정 범위가 크다. Docker, 데스크톱 앱, 웹 UI, 코드 방식이 모두 있어 배포 방식 선택지는 많다. 반면 외부 공개 기능을 켜면 비밀번호를 따로 잡아야 하고, 서버 쪽 도구 기능이 기본으로 켜져 있어 노출 범위를 직접 줄여야 한다.

사내 도입 체크

  • 외부 API 호출은 선택 사항이다. 로컬 모델만 쓸 수 있지만, OpenAI·Anthropic 같은 제공자와도 같은 화면에서 섞어 쓸 수 있다고 적혀 있다.
  • Cloudflare HTTPS로 원격 공개할 수 있어 데이터 반출과 외부 노출 가능성이 있다. 공개 시 비밀번호와 도구 비활성화 설정을 확인해야 한다.
  • 유지보수 주체는 unslothai 조직이다.
  • 상용 대체재는 많다. 다만 로컬 실행, 학습, 에이전트 연결, API 공개를 한 제품군에 넓게 묶은 점이 차별점이다.

주요 용어

파인튜닝(Fine-tuning): 기존 모델을 특정 업무 데이터로 추가 학습하는 방식 VRAM: GPU가 쓰는 전용 메모리 GGUF: 경량 실행에 자주 쓰는 모델 파일 형식 MLX: Apple 실리콘 환경에서 모델 실행에 쓰는 프레임 RAG(Retrieval-Augmented Generation): 외부 문서를 찾아 답변에 반영하는 방식 LoRA: 적은 자원으로 모델을 추가 학습하는 기법
