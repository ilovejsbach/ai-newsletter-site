터미널에서 바로 쓰는 Gemini 작업창

★ 107,130이번 주 +123TypeScriptApache-2.0 사내 사용 가능릴리스 v0.60.0 (09.15)최근 활동 09.22테스트 없음예제 없음AGENTS.md 없음

Google은 이 도구를 Gemini를 터미널에서 직접 쓰게 해 주는 오픈소스 AI 에이전트로 소개한다. 개인 Google 계정 로그인, Gemini API 키, Vertex AI까지 인증 방법도 나눠 뒀다. 파일 작업과 셸 명령, 웹 검색 같은 기본 도구를 안에 넣었고, MCP로 외부 기능도 붙일 수 있다. 스크립트용 비대화식 실행과 GitHub Action 연동도 지원한다.

무엇을 하는 물건인가

Gemini CLI는 터미널에서 Gemini에게 일을 시키는 명령줄 도구다. 코드를 읽고 고치거나, 파일을 찾고, 웹 정보를 확인하는 일을 한 화면에서 처리한다. 이 도구가 없으면 사람은 창을 여러 개 띄워 놓고 검색과 파일 수정, 명령 실행을 따로 해야 한다. 문서 보관함에서 필요한 종이와 메모를 한 번에 꺼내 보는 비서에 가깝다.

스펙과 도입 조건

  • TypeScript로 작성됐다.
  • npm 전역 설치, Homebrew, MacPorts, Anaconda 환경 설치를 지원한다.
  • Dockerfile이 포함돼 있다.
  • Google 계정 로그인, Gemini API 키, Vertex AI 가운데 하나가 필요하다.
  • 라이선스는 Apache-2.0이다.
  • 최신 릴리스는 v0.60.0이며, 프리뷰는 매주 화요일 UTC 23:59, 스테이블은 매주 화요일 UTC 20:00, 나이틀리는 매일 UTC 00:00에 나온다.

이럴 때 쓰면 좋다

  • 야간 배치 장애가 났을 때 운영자가 터미널에서 로그와 파일을 함께 보며 원인 후보를 빠르게 정리할 때 쓸 수 있다.
  • 개발팀이 사내 GitHub에서 풀리퀘스트 검토와 이슈 라벨 분류를 자동화하려 할 때 맞다.
  • 규정 반영으로 여러 디렉터리의 설정 파일을 함께 점검하고 수정 초안을 만들 때 유용하다.

핵심 기능

  • 큰 코드베이스를 질의하고 수정할 수 있다.
  • Google Search 기반 검색, 파일 작업, 셸 명령, 웹 가져오기를 기본 도구로 제공한다.
  • 대화 체크포인트와 GEMINI.md 문맥 파일로 작업을 저장하고 다시 이어갈 수 있다.

대안 대비 차별점

이 도구는 Gemini를 터미널에서 바로 쓰는 데 초점을 맞췄다. Google Search, 파일 작업, 셸 명령, 웹 가져오기를 기본으로 넣어 별도 연결 없이 바로 쓸 수 있다. MCP 서버를 붙여 Imagen, Veo, Lyria 같은 기능까지 늘릴 수 있게 해 확장 경로도 분명하다. 스크립트용 비대화식 실행과 GitHub Action 연동이 있어 개인 도구에 그치지 않고 팀 자동화까지 이어서 쓸 수 있다.

사내 도입 체크

  • 외부 API 호출이 있다. Google 계정 로그인, Gemini API 키, Vertex AI 가운데 한 방식을 써야 한다.
  • 웹 검색과 웹 가져오기, GitHub 연동 기능을 쓰면 데이터 반출 범위를 먼저 점검해야 한다.
  • 유지보수 주체는 Google 조직이다.
  • 상용 대체재는 있다. 다만 이 도구는 오픈소스이며 Gemini와 GitHub 자동화, MCP 확장을 한 묶음으로 제공한다.

주요 용어

터미널(Terminal): 글자로 명령을 입력해 작업하는 화면 명령줄 인터페이스(CLI): 마우스 대신 명령어로 쓰는 프로그램 방식 MCP(Model Context Protocol): 모델에 외부 도구를 붙이는 연결 규칙 OAuth: 계정 로그인으로 권한을 확인하는 인증 방식 Vertex AI: Google Cloud에서 쓰는 기업용 AI 서비스
