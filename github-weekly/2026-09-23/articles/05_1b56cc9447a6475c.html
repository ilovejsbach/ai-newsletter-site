HKUDS/Vibe-Trading

시장 데이터와 백테스트를 묶은 트레이딩 에이전트

★ 33,848이번 주 +336PythonMIT 사내 사용 가능릴리스 v0.1.15 (09.09)최근 활동 09.22테스트 없음예제 없음AGENTS.md 없음

트레이딩용 AI 도구는 화려한 전략보다 데이터 취급 방식이 더 중요할 때가 많다. 어떤 가격을 썼는지, 공급원이 거절한 질의를 빈 데이터로 오해하지 않았는지, 백테스트가 언제 멈췄는지가 결과를 크게 바꾼다. Vibe-Trading은 이런 운영 디테일을 자주 고치고 기능을 넓히는 흐름을 보인다. 이번에 공개된 변경 사항도 대부분 데이터 근거와 실행 안전장치에 몰려 있다.

무엇을 하는 물건인가

Vibe-Trading은 시장 데이터 조회와 백테스트, 계좌 연결 기능을 한 명령으로 붙이는 트레이딩 에이전트 도구다. 시장 데이터와 전략 검증, 메시지 채널 설정, 포트폴리오 조회를 한곳에서 다루게 한다. 이 도구가 없으면 데이터 공급원과 백테스트 도구, 알림 설정을 각각 따로 붙이고 결과도 따로 맞춰 봐야 한다. 여러 증권 화면과 엑셀, 메신저를 오가며 장부를 맞추던 일을 한 책상으로 모으는 쪽에 가깝다.

스펙과 도입 조건

  • 언어는 Python이다.
  • Dockerfile이 있다.
  • API와 MCP 항목을 안내한다.
  • 라이선스는 MIT다.
  • 최신 릴리스는 v0.1.15다.
  • 테스트와 예제 제공 여부는 표시돼 있지 않다.

이럴 때 쓰면 좋다

  • 퀀트 전략 후보를 실제 주문 전 단계에서 과거 데이터로 검증하고 자금 부족 시 동작까지 점검할 때 쓸 수 있다.
  • 고객 자산 현황이나 사내 모의 포트폴리오를 여러 데이터 공급원으로 조회해 근거를 맞춰 봐야 할 때 어울린다.
  • 메신저 알림 채널을 붙여 야간 시장 감시 결과나 백테스트 완료 신호를 운영자가 바로 받으려는 팀에 맞다.

핵심 기능

  • 시장 데이터 조회와 백테스트를 지원한다.
  • Shadow Account와 API, MCP 관련 항목을 제공한다.
  • Binance, Futu, Trading 212 잔고 표시와 Robinhood 읽기 전용 계좌 조회 같은 연결 기능을 포함한다.

대안 대비 차별점

이 저장소는 트레이딩 기능만 나열하지 않고 데이터 근거를 세밀하게 검증하는 쪽에 힘을 준다. 예를 들어 공급원이 질의를 거절했는지, 실제로 데이터가 비어 있는지 구분해 처리하려고 고쳤다. VaR 수치가 참조한 필드와 맞는지도 점검하도록 손봤다. 메신저 채널 설정을 웹 화면에서 바꾸고 저장 전 연결 시험을 하는 기능도 넣어 운영 편의를 같이 챙긴다.

사내 도입 체크

  • 외부 데이터 공급원과 계좌 연동 기능이 있어 외부 API 호출은 사실상 있다고 보는 편이 맞다.
  • 계좌 잔고와 시장 데이터가 오갈 수 있어 데이터 반출 범위와 저장 위치를 확인해야 한다.
  • 유지보수 주체는 HKUDS라는 조직 계정이다.
  • 상용 퀀트 플랫폼과 백테스트 제품이 있어 대체 제품은 있다.

주요 용어

백테스트(Backtest): 과거 데이터로 전략을 시험하는 검증 방식 VaR(Value at Risk): 일정 신뢰수준에서 예상 손실 규모를 나타내는 위험 지표 ETF(Exchange Traded Fund): 거래소에서 주식처럼 사고파는 펀드 MCP(Model Context Protocol): 모델과 외부 도구를 연결하는 규약 Shadow Account: 실제 주문 없이 계좌 흐름만 모의로 보는 기능
