가치투자 조사 절차를 AI 팀으로

스타 16,194 · 이번 주 +0 · HTML · MIT 사내 사용 가능 · 최근 릴리스 v1.0.0 (04.07) · 테스트 있음 · 예제 없음 · AGENTS.md 있음

이 저장소는 투자 조사 과정을 AI 스킬 모음으로 정리했다. 대상 도구는 Claude Code와 Codex다. 저장소 소개는 네 투자자의 방법론과 다중 에이전트 병렬 조사를 앞세운다. 릴리스 v1.0.0에는 다섯 개 스킬이 포함됐다.

무엇을 하는 물건인가

이 저장소는 가치투자 조사 절차를 AI 명령 세트로 정리한 스킬 모음이다. 애널리스트 팀이 하던 조사 항목을 미리 정해 둔 항목별 작업처럼 꺼내 쓰는 방식에 가깝다. 사용자는 종목 조사, 산업 조사, 체크리스트 점검, 비상장사 조사 같은 작업을 나눠 실행할 수 있다. 한 사람에 Claude Code나 Codex를 더해 투자 리서치 팀처럼 쓰겠다는 구상이다.

스펙과 도입 조건

  • 저장소 언어 표기는 HTML이다.
  • Claude Code용 명령 파일을 복사해 쓰는 형태로 보인다.
  • Claude Code 또는 Codex가 필요하다.
  • 라이선스는 MIT다.
  • 최신 릴리스는 v1.0.0이며 발췌 정보에는 릴리스 주기가 없다.

이럴 때 쓰면 좋다

  • 기업 여신 심사 전에 특정 상장사의 사업 구조와 산업 위치를 빠르게 훑는 내부 참고 조사에 맞는다.
  • 자산관리 부서가 투자 아이디어를 모을 때 체크리스트 기반으로 조사 항목을 통일하는 데 쓸 수 있다.
  • 비상장 핀테크 업체와 협업을 검토하면서 공개 정보만으로 기초 조사를 정리할 때 유용하다.

핵심 기능

  • 네 투자자의 방법론을 합친 종합 투자 조사를 지원한다.
  • 네 개 AI 에이전트가 병렬로 조사하는 팀 모드를 제공한다.
  • 산업 전반 조사와 비상장사 심층 조사용 스킬을 따로 둔다.

왜 지금 주목받나

이 저장소는 투자 조사를 단순 질의응답이 아니라 역할별 스킬 묶음으로 정리해 관심을 끈다. 특히 종합 분석, 병렬 조사, 체크리스트, 산업 스캔, 비상장사 조사까지 조사 유형을 나눠 둔 점이 눈에 띈다. 다만 성과 수치로 제시한 2024년 연간 수익률 +69.29%는 저장소 운영자가 밝힌 실적일 뿐이며, 같은 발췌에는 예시나 독립 검증 조건이 붙어 있지 않다.

사내 도입 체크

  • Claude Code 또는 Codex에 조사 내용을 보내는 구조라면 데이터 반출 가능성을 먼저 따져야 한다.
  • 외부 API 키 필요 여부는 발췌 정보만으로 확인되지 않는다.
  • 유지보수 주체는 개인 계정으로 보인다.
  • 투자 조사 SaaS나 사내 리서치 템플릿으로 일부 대체할 수 있는지 비교가 필요하다.
