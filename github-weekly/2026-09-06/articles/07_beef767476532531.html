Claude Code 팀 운영법을 모은 참고서

★ 65,665HTMLMIT 사내 사용 가능최근 활동 09.06테스트 없음예제 없음AGENTS.md 없음

이 저장소는 Claude Code를 잘 쓰는 법을 모아 둔 참고서다. 단일 기능 도구가 아니다. 팀이 프롬프트와 역할, 작업 순서를 어떻게 나눌지 정리하는 데 초점을 둔다. 비개발자에게는 AI 협업 절차를 문서화하는 사례집으로 볼 수 있다.

무엇을 하는 물건인가

이 저장소는 Claude Code 활용법을 주제별로 모아 놓은 가이드다. 에이전트와 명령, 스킬, 훅, 워크플로를 어디에 두고 어떻게 조합할지 보여 준다. 한 번에 설치해 끝나는 도구보다, 팀의 작업 규칙집을 만드는 재료 모음에 가깝다. 사내 업무 매뉴얼과 체크리스트를 한 서가에 정리해 둔 형태로 보면 이해가 쉽다.

스펙과 도입 조건

  • 언어 표시는 HTML이다.
  • 별도 릴리스는 없다.
  • 설치 패키지나 Docker 이미지는 확인되지 않았다.
  • 외부 API 키 필요 여부는 확인되지 않았다.
  • 라이선스는 MIT다.

이럴 때 쓰면 좋다

  • 사내 AI 코딩 가이드를 만들 때 에이전트와 명령, 스킬의 역할을 나눠 정리하는 참고자료로 쓸 수 있다.
  • 개발팀이 코드 리뷰와 계획 수립, QA 점검 절차를 AI 도구와 묶어 표준화하려 할 때 도움이 된다.
  • 여러 모델을 함께 쓰는 파일럿에서 Claude Code와 Codex 같은 도구의 분업 방식을 살필 때 적합하다.

핵심 기능

  • Research → Plan → Execute → Review → Ship 구조의 개발 워크플로를 정리한다.
  • Claude Code와 다른 모델을 Plugin, MCP, Router 세 방식으로 함께 쓰는 흐름을 모은다.
  • 팁과 트릭 83개를 프롬프팅, 세션 관리, 규칙 파일, 디버깅 등 주제별로 분류한다.

대안 대비 차별점

이 저장소는 공식 문서처럼 한 기능을 설명하기보다 커뮤니티 실천법을 한곳에 묶는다. command → agent → skill 패턴을 구현 예시와 함께 보여 준다. /weather-orchestrator를 완성형 예제로 앞세운다. 다른 모델과 함께 쓰는 방법도 세 갈래로 나눈다. 다른 모델 CLI를 Claude Code 안에서 돌리는 Plugin 방식이 있다. Model Context Protocol로 도구처럼 부르는 MCP 방식도 있다. API 종단점을 다른 제공자로 바꾸는 Router 방식도 실었다. 저장 위치 표도 있어 팀 규칙 파일과 설정 파일을 어디에 둘지 빠르게 훑을 수 있다.

기능위치설명

Hooks.claude/hooks/가이드
Settings.claude/settings.json권한, 모델 설정, 출력 형식, 샌드박싱 등

사내 도입 체크

  • 외부 API 호출 여부는 저장소만으로 확인되지 않는다.
  • 예시와 링크가 많아 사내 표준 문서로 쓰려면 선별과 검증이 필요하다.
  • 유지보수 주체는 개인 개발자 shanraisshan이다.
  • 상용 제품을 대체한다기보다, 기존 AI 코딩 도구의 운영 가이드를 보완하는 자료에 가깝다.

주요 용어

에이전트(Agent): 특정 역할을 맡아 단계적으로 작업하는 AI 구성 스킬(Skill): 자주 쓰는 작업 절차를 재사용하는 단위 훅(Hook): 특정 시점에 자동 실행하는 연결 지점 MCP(Model Context Protocol): 도구나 모델을 연결하는 규약 라우터(Router): 요청을 다른 모델 제공자로 넘기는 방식
