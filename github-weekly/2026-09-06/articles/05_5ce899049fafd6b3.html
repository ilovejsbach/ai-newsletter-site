문서에서 바로 파워포인트 초안 만들기

★ 52,339PythonMIT 사내 사용 가능릴리스 v6.3.0 (09.05)최근 활동 09.05테스트 없음예제 없음AGENTS.md 있음

이 저장소는 문서에서 바로 PowerPoint 초안을 만드는 작업을 겨냥한다. 결과물은 스크린샷 묶음이 아니다. 파워포인트에서 다시 편집할 수 있는 실제 슬라이드를 만든다. 이번 버전은 차트와 표, 글자 폭 계산, 템플릿 설치 쪽 정확도를 손봤다.

무엇을 하는 물건인가

이 도구는 문서나 주제를 실제 PowerPoint 파일로 바꿔 준다. 기본 도형과 전환, 애니메이션을 파워포인트 기본 요소로 넣는다. 차트와 표도 필요할 때 만든다. 보고서 초안을 디자이너에게 넘기기 전, 발표용 골격을 먼저 잡아 주는 비서에 가깝다.

스펙과 도입 조건

  • Python 저장소다.
  • GitHub가 공식 배포처다. AtomGit은 미러다.
  • 사용자 .pptx 템플릿을 지원한다.
  • 라이선스는 MIT다. 저작자 표기가 필요하다.
  • 최신 릴리스는 v6.3.0이다.

이럴 때 쓰면 좋다

  • 주간 실적 보고 문서를 임원 보고용 슬라이드 초안으로 빨리 바꿔야 할 때 쓸 만하다.
  • 규정 개정안이나 제안서를 사내 템플릿 발표자료로 옮길 때 손작업을 줄일 수 있다.
  • 교육 자료를 만들 때 발표자 노트까지 포함한 설명형 슬라이드를 먼저 만들기 좋다.

핵심 기능

  • 문서나 주제를 실제 PowerPoint 덱으로 생성한다.
  • 네이티브 차트와 표를 만들어 파워포인트 안에서 다시 수정할 수 있다.
  • 발표자 노트에서 오디오 내레이션을 만든다.

대안 대비 차별점

이 저장소는 결과물을 이미지가 아닌 네이티브 PowerPoint로 만든다고 내세운다. 이번 릴리스에서는 네이티브 차트가 작성된 SVG를 항목별로 따라가도록 바꿨다. 막대 순서와 점 표시, 점별 색상, 영역 채우기, 선 시작 위치 같은 요소도 SVG에서 반영한다. 표는 채우지 않은 셀을 noFill로 내보내고, 작성된 행 높이를 우선 반영한다. 글자 폭은 Arial, Times New Roman, Georgia, Verdana, Calibri의 실제 글리프 폭 표를 써서 계산한다. 템플릿은 한 번에 설치할 수 있게 바뀌었다. 예제 라이브러리는 33개 덱으로 늘었다. Create Template와 Edit Native PPTX는 버그 수정만 받고 새 개발은 멈춘 상태다.

사내 도입 체크

  • 외부 API 호출 여부는 확인 필요다.
  • 문서 내용을 입력값으로 쓰므로 데이터 반출 가능성은 확인이 필요하다.
  • 유지보수 주체는 개인 개발자 Hugo He다.
  • PowerPoint 초안 자동화 도구와 겹치는 상용 제품은 있지만, 이 저장소는 .pptx 템플릿과 네이티브 편집성을 함께 앞세운다.

주요 용어

네이티브 PowerPoint(Native PowerPoint): 이미지가 아니라 파워포인트 안에서 직접 수정되는 요소 SVG: 화면에 그린 도형과 선 정보를 담는 벡터 형식 템플릿(Template): 회사 서식이 들어 있는 .pptx 바탕 파일 발표자 노트(Speaker notes): 발표자가 보는 슬라이드별 메모
