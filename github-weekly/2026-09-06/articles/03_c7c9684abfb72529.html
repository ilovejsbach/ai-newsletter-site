이 저장소는 AI 기반 침투 테스트 도구다. 코드 저장소, 배포된 웹앱, API 명세를 대상으로 실제 공격 절차를 자동 수행한다. 결과는 단순 경고가 아니라 재현 가능한 공격 예시까지 붙여 보여주려 한다. 이번 주 릴리스와 함께 CI/CD 연동 메시지를 전면에 내세웠다.

무엇을 하는 물건인가

Strix는 애플리케이션 취약점을 찾고 검증하는 오픈소스 AI 침투 테스트 도구다. 에이전트가 정찰, 공격, 검증을 차례로 수행한다. 보안팀이 직접 반복 점검하던 일을, 도구가 먼저 자동으로 돌려 보게 한다. 결과에는 실제 동작한 PoC와 수정 가이드도 포함할 수 있다.

스펙과 도입 조건

  • 언어는 Python이다.
  • 설치 형태는 로컬 CLI 실행이다. 첫 실행 때 샌드박스 Docker 이미지를 자동으로 내려받고, 로컬 웹 뷰어도 제공한다.
  • 의존 서비스는 실행 중인 Docker와 지원되는 LLM API Key가 필요하다.
  • 라이선스는 Apache-2.0이다.
  • 성숙도는 v1.6.2 릴리스가 있고, GitHub Actions와 CI/CD 파이프라인 연동을 새 기능으로 강조한다.

대안 대비 차별점

이 도구는 정적 분석만 하는 스캐너와 달리, 코드를 실제로 실행하고 취약점을 PoC로 검증하는 점을 앞세운다. 웹앱, GitHub 저장소, API 명세를 같은 CLI에서 다룰 수 있는 것도 차이다. 코딩 에이전트와의 연결도 열어 두었다. Claude Code, Cursor, Codex 같은 에이전트가 같은 엔진으로 점검·수정·CI 설정을 실행할 수 있다.

이럴 때 쓰면 좋다

  • 인터넷뱅킹 프런트엔드 개편 전 인증 우회나 권한 통제 문제를 빠르게 훑어볼 때 쓸 수 있다.
  • API 게이트웨이 팀이 OpenAPI 문서를 기준으로 선언된 모든 엔드포인트를 출시 전 점검할 때 적합하다.
  • DevSecOps 조직이 pull request마다 자동 보안 검사를 걸어 취약한 코드 병합을 막고 싶을 때 유용하다.

핵심 기능

  • 정찰, 공격, 검증 도구를 묶어 OWASP Top 10과 그 밖의 취약점을 폭넓게 점검한다.
  • 멀티 에이전트 오케스트레이션으로 정찰·공격·후속 분석 역할을 나눠 병렬 실행한다.
  • 로컬 디스크에 실행 결과를 저장하고, 웹 뷰어에서 취약점·에이전트 맵·과거 실행 이력을 보여준다.

사내 도입 체크

  • 외부 LLM API Key가 필요하다. 소스 코드나 대상 URL, 발견 내역이 외부 모델 호출에 포함될 수 있어 반출 범위 확인이 필요하다.
  • 로컬 웹 뷰어는 기본적으로 127.0.0.1에 바인딩하고 토큰 링크를 출력한다. 다른 장비에서 열 때 공유 통제가 필요하다.
  • 유지보수 주체는 usestrix 조직 계정이다.
  • Strix Cloud와 Enterprise 상품이 따로 있다. 오픈소스판으로 내부 검증 후 상용 전환 여부를 비교할 수 있다.

주요 용어

침투 테스트(Penetration testing): 실제 공격 기법으로 시스템 약점을 점검하는 보안 진단 PoC(Proof of Concept): 취약점이 실제로 작동함을 보이는 재현 코드나 절차 정적 분석(SAST): 코드를 실행하지 않고 소스만 보고 취약점을 찾는 방식 동적 분석(DAST): 실행 중인 앱에 요청을 보내 취약점을 찾는 방식 CI/CD: 코드 변경부터 테스트·배포까지 자동화한 개발 흐름 OWASP Top 10: 웹 애플리케이션 대표 취약점 분류 목록
