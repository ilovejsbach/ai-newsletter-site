RTX 3090 한 장으로 27B 모델 돌리는 법

★ 1,162PythonApache-2.0 사내 사용 가능최근 활동 09.04테스트 없음예제 없음AGENTS.md 없음

이 저장소는 범용 추론 엔진이 아니라 특정 하드웨어 조합을 위한 실전 레시피다. 목표는 RTX 3090 한 장으로 Qwen3.8-27B를 길게, 빠르게, API 형태로 돌리는 일이다. 어떤 옵션이 속도를 올리고 어떤 옵션이 동시성을 깎는지도 자세히 적었다. 숫자는 많지만, 핵심은 한 장비 안에서 무엇을 포기하고 무엇을 얻는지 공개했다는 점이다.

무엇을 하는 물건인가

이 저장소는 RTX 3090 한 장에서 Qwen3.8-27B를 vLLM으로 돌리는 설정 묶음이다. 24 GB 소비자용 GPU 한 장으로 OpenAI 호환 API를 열도록 맞췄다. 단일 사용자용 모드와 다중 동시 요청용 모드를 미리 나눠 뒀다. 작은 지점 창구 하나로 개인 상담과 단체 접수를 각각 어떻게 운영할지 정해둔 운영 매뉴얼에 가깝다.

스펙과 도입 조건

  • Python 기반 저장소다.
  • Docker 이미지가 있다.
  • Docker Compose 프로필로 single 모드와 batch 모드를 고를 수 있다.
  • 이미지 크기는 첫 시작 때 9.5 GB를 받는다.
  • 첫 시작 때 모델을 내려받고 재양자화하며 약 20 GB를 ./models에 저장한다.
  • 기본 서비스 포트는 18020이다.
  • OpenAI 호환 API를 제공한다.
  • 기본 상태에서는 인증이 없다.
  • API 키는 .env나 api_key.txt로 넣을 수 있다.
  • 수동 설치는 venv 절차도 제공한다.
  • 라이선스는 Apache-2.0이다.
  • 릴리스는 없다.

이럴 때 쓰면 좋다

  • 예산이 큰 GPU 서버까지 쓰기 전, 사내 실험실 PC 한 대로 규정 문서 검색 챗봇의 체감 속도를 먼저 검증할 때 적합하다.
  • 소수 사용자가 길고 큰 문서를 반복해서 묻는 내부 심사 지원 도구를 만들 때 prefix cache 효과를 시험하기 좋다.
  • 고객센터 지식검색처럼 동시 요청이 많은 업무와 개인 분석형 업무를 single 모드와 batch 모드로 나눠 비교할 때 유용하다.

핵심 기능

  • single 모드와 batch 모드 두 가지 준비된 실행 방식을 제공한다.
  • DFlash2, MTP, prefix cache 같은 옵션으로 속도와 문맥 길이를 조정한다.
  • 패치, 재양자화 스크립트, 검증 스크립트, 벤치마크 절차를 함께 제공한다.

성능과 운영 비용

이 저장소는 한 장의 RTX 3090에서 어느 정도 성능이 나오는지 수치를 자세히 적었다. 동시 요청 64건에서는 약 1,000 tok/s를 적었다. 단일 사용자에서는 기본 샘플링 기준 약 114 tok/s, greedy 기준 약 124 tok/s를 적었다. 문맥 길이는 150k~262k라고 소개한다.

측정 조건도 함께 밝혔다. 단일 스트림 수치는 2026-08-22에 현재 main 브랜치에서 다시 쟀다. vllm bench serve와 실사용 프롬프트 8개, 출력 1024 토큰, 동시성 1 조건을 썼다. 전력 제한은 RTX 3090의 250 W다.

옵션에 따른 교환관계도 분명하다. SPEC=dflash2와 PREFIX_CACHE=1은 단일 사용자 모드에서 큰 이득을 준다. 문서 인용이나 편집처럼 프롬프트를 많이 되받아 쓰는 작업에서는 DFLASH_TOKENS=15가 유리하다고 적었다. 반면 이 설정은 요청 슬롯을 절반으로 줄이고 문맥도 8k 줄인다.

prefix cache 효과는 특히 크다. 같은 25k 토큰 문서에 대한 두 번째 턴은 첫 토큰 시간이 22.4초에서 0.56초로 줄었다고 적었다. 답변 내용은 토큰 단위로 같다고 밝혔다. 다만 KVarN 기반의 큰 문맥 모드는 4/2비트 KV 캐시를 써서 손실이 생길 수 있다고 단서를 달았다.

사내 도입 체크

  • 기본 상태에서는 인증이 없다. 개인 PC 밖으로 열면 API 키를 먼저 넣어야 한다.
  • 서버가 0.0.0.0으로 열리므로 네트워크 노출 범위를 따로 통제해야 한다.
  • 모델 다운로드와 재양자화 과정이 들어간다. 모델 파일 저장 위치와 반출 통제를 확인해야 한다.
  • 유지보수 주체는 개인 개발자다.
  • 소형 상용 추론 서버나 유료 API 실험을 일부 대체할 수 있지만, 기업용 지원과 장기 유지보수는 확인이 필요하다.

주요 용어

동시성(Concurrency): 여러 요청을 겹쳐 처리하는 정도 토큰(Token): 모델이 문장을 처리할 때 쓰는 최소 단위 문맥 길이(Context Length): 모델이 한 번에 참고할 수 있는 입력 길이 추측 디코딩(Speculative Decoding): 초안 모델로 후보를 먼저 만들고 본모델이 빠르게 검증하는 가속 기법 Prefix Cache(Prefix Cache): 이미 보낸 긴 입력의 계산 결과를 재사용하는 캐시
