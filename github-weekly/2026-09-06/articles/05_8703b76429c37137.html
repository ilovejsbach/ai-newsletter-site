퇴근 뒤 자동으로 오는 주식 분석 대시보드

스타 64,670 · 이번 주 +0 · Python · MIT 사내 사용 가능 · 최근 릴리스 v3.31.0 (08.23) · 테스트 있음 · 예제 없음 · AGENTS.md 있음

이 저장소는 주식 분석 업무를 자동 보고 체계로 바꾸는 데 초점을 맞춘다. 종목 시세와 뉴스, 공시성 정보, 전략 질문 기능을 한 화면과 한 알림 흐름으로 묶었다. 서버 없이 GitHub Actions로 돌릴 수 있다는 점도 앞세운다. 금융IT 조직에서는 사내 시황 요약, 관심 종목 모니터링, 테스트용 리서치 자동화에 맞닿아 있다.

무엇을 하는 물건인가

이 저장소는 관심 종목의 시세와 뉴스, 분석 의견을 모아 매일 보고서로 보내는 주식 분석 시스템이다. 사용자는 종목 목록과 AI 모델, 알림 채널을 정하면 된다. 그러면 시스템이 시장별 데이터를 읽고 결과를 보기 쉽게 대시보드로 정리한다. 매일 반복하던 시황 메일 초안을 자동으로 받아보는 업무 도구에 가깝다.

스펙과 도입 조건

  • 언어는 Python이다.
  • 설치 형태는 GitHub Actions 실행, 로컬 실행, Docker 배포를 지원한다.
  • WebUI는 브라우저에서 접속해 쓴다.
  • AI 분석을 쓰려면 최소 1개의 외부 AI API 키가 필요하다.
  • 알림을 쓰려면 최소 1개의 알림 채널 설정이 필요하다.
  • 뉴스 품질을 높이려면 검색 서비스 설정을 권장한다.
  • 무료 시세 데이터원은 기본 내장이라 초기 설정 없이 실행할 수 있다.
  • 라이선스는 MIT다.
  • 최신 릴리스는 v3.31.0이다.

이럴 때 쓰면 좋다

  • 야간 배치 뒤에 관심 종목과 시장 복기 내용을 사내 메신저로 자동 전송하고 싶을 때 쓸 수 있다.
  • 고객사나 자산운용 부서가 보는 종목군의 뉴스와 리스크 요인을 매일 같은 형식으로 정리할 때 맞다.
  • 리서치 인력이 적은 팀이 해외 시장까지 포함한 종목 점검을 먼저 자동 초안으로 받고 수작업 검토를 붙일 때 유용하다.

핵심 기능

  • A주, 홍콩, 미국, 일본, 한국, 대만 주식과 ETF 데이터를 모아 분석 보고서를 만든다.
  • 기업용 메신저, Telegram, Discord, Slack, 이메일로 결과를 자동 발송한다.
  • Web 작업대에서 수동 분석, 작업 모니터링, 과거 보고서 조회, 백테스트, 보유 포지션 관리를 지원한다.

이번 릴리스에서 바뀐 점

v3.31.0은 Agent 도구 호출의 시간 제한을 더 세밀하게 나눴다. 범주별과 개별 도구별 시간 제한을 둘 수 있고, 중복 재시도 방지와 병렬 실행 예산, 협업 취소, 런타임 재적용도 보강했다. 서비스가 다시 시작된 뒤 예약 작업을 복구하는 기능도 고쳤다. 뉴스 검색 결과가 비면 보고서에 근거 한계를 그대로 드러내도록 바꿨고, 데스크톱 업데이터 의존성은 builder-util-runtime 9.7.0으로 올려 CVE-2026-54673에 적힌 HTTP 리다이렉트 자격증명 헤더 노출 위험을 줄였다.

사내 도입 체크

  • 외부 AI API 호출이 기본 전제다. 종목명, 질의 내용, 생성 보고서가 외부 서비스로 나갈 수 있는지 확인이 필요하다.
  • 무료 시세 데이터원과 검색 서비스는 상위 서비스의 속도 제한과 인터페이스 변경 영향을 받는다.
  • 유지보수 주체는 개인과 기여자들로 보인다. 사내 운영 도구로 쓸 때는 업데이트 대응 체계를 따로 잡아야 한다.
  • 시황 알림, 리서치 자동화, 협업 메신저 통보는 일부 상용 시장정보·알림 제품으로 대체할 수 있다.

주요 용어

LLM(Large Language Model): 긴 문장과 자료를 읽고 요약·분석하는 AI 모델 GitHub Actions: 깃허브에서 정해진 시간이나 조건에 맞춰 작업을 자동 실행하는 기능 Webhook: 다른 서비스로 알림을 보내는 연결 주소 Fallback: 기본 경로가 실패할 때 예비 경로로 자동 전환하는 방식 WebUI(Web User Interface): 브라우저에서 쓰는 관리 화면
