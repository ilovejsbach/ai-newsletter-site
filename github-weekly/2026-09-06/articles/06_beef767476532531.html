코딩 에이전트 운용법을 한곳에 모은 안내서

스타 65,634 · 이번 주 +0 · HTML · MIT 사내 사용 가능 · 테스트 없음 · 예제 없음 · AGENTS.md 없음

이 저장소는 프로그램을 설치해 바로 쓰는 제품이 아니다. Claude Code를 체계적으로 쓰기 위한 운영 지침과 예시 모음을 제공한다. 문서 구조는 에이전트, 명령, 스킬, 훅, 세션 관리처럼 실무 운영 단위에 맞춰 짜였다. 비개발자도 AI 도구를 팀 규칙에 맞게 다듬는 법을 익힐 수 있어 학습 가치가 있다.

무엇을 하는 물건인가

이 저장소는 Claude Code를 잘 쓰기 위한 사용 설명서이자 예제 모음이다. 어떤 일을 에이전트로 맡기고, 어떤 일은 명령이나 스킬로 쪼갤지 정리해 둔다. 한 명의 숙련자가 구두로 전하던 노하우를 문서와 템플릿으로 옮긴 형태에 가깝다. 이 저장소는 작업 도구라기보다 먼저 읽는 참고서에 가깝다.

스펙과 도입 조건

  • 주 언어 표기는 HTML이다.
  • 설치 패키지나 실행 바이너리 정보는 확인되지 않았다.
  • Claude Code 환경을 전제로 한 문서와 설정 파일 구조를 다룬다.
  • 외부 API 키 필요 여부는 저장소 본문에서 확인되지 않았다.
  • 라이선스는 MIT다.
  • 별도 릴리스는 없다.

이럴 때 쓰면 좋다

  • 사내 개발팀이 AI 코딩 도구를 도입했는데 팀 공통 작업 순서와 검토 규칙을 먼저 정해야 할 때 참고할 수 있다.
  • 운영 자동화나 배치 스크립트 수정 업무에서 계획, 실행, 검토 단계를 AI에 어떻게 나눌지 설계할 때 도움이 된다.
  • 여러 모델을 함께 써야 하는 조직이 어떤 작업을 주 모델에 두고 어떤 작업을 보조 모델에 넘길지 기준을 잡을 때 유용하다.

핵심 기능

  • Research → Plan → Execute → Review → Ship 구조의 개발 워크플로를 정리한다.
  • 에이전트, 명령, 스킬, 훅, 메모리 파일의 위치와 역할을 한 표로 보여준다.
  • Claude Code에 다른 모델을 플러그인, MCP, 라우터 방식으로 붙이는 교차 모델 운용법을 소개한다.

대안 대비 차별점

비슷한 저장소가 링크 모음에 그치는 경우가 많지만, 이 저장소는 실제 파일 위치와 호출 방식까지 묶어 설명한다. 특히 command → agent → skill 흐름을 하나의 패턴으로 제시해 팀 규칙 설계에 바로 가져다 쓰기 쉽다. 플러그인, MCP, 라우터처럼 다른 모델을 붙이는 방법도 나눠 보여줘 단일 모델 사용법에 머무르지 않는다.

기능위치설명
Subagents.claude/agents/.md하위 에이전트 정의
Commands.claude/commands/.md명령 정의
Skills.claude/skills//SKILL.md스킬 정의
Hooks.claude/hooks/자동 실행 연결 동작
Settings.claude/settings.json권한, 모델 설정, 샌드박스 등
MemoryCLAUDE.md, .claude/rules/ 등규칙과 기억 관리

사내 도입 체크

  • 이 저장소 자체는 문서 모음이라 직접 데이터 반출은 없다. 다만 실제 사용 대상인 Claude Code와 연결 모델은 외부 호출 여부를 따로 확인해야 한다.
  • 유지보수 주체는 개인으로 보인다. 조직 차원의 장기 지원은 확인이 필요하다.
  • 상용 대체재는 있다. 일부 AI 코딩 도구 벤더가 가이드와 템플릿을 제공하지만, 이 저장소처럼 커뮤니티 관행을 넓게 모은 형태는 별도 비교가 필요하다.

주요 용어

Agent: 목표를 받아 여러 단계 작업을 스스로 진행하는 AI 실행 단위 Skill: 특정 작업 절차를 재사용하도록 정리한 기능 묶음 Hook: 특정 시점에 자동으로 실행되는 연결 동작 MCP(Model Context Protocol): 모델이 외부 도구나 다른 모델을 호출하는 연결 규약 CLI(Command Line Interface): 터미널에서 명령어로 쓰는 실행 방식
