코드 보안 점검을 자동화하는 CLI

★ 10,491TypeScriptApache-2.0 사내 사용 가능릴리스 npm-v0.1.25 (09.02)최근 활동 09.06테스트 없음예제 있음AGENTS.md 있음

이 저장소는 코드 보안 점검을 자동화하려는 팀을 겨냥한다. 한 번 점검하고 끝나는 도구보다, 결과를 저장하고 다시 비교하는 흐름에 무게를 둔다. Docker 구성과 findings 서비스도 함께 제공한다. 이번 릴리스는 중복 판정과 점검 이력 유지 쪽을 손봤다.

무엇을 하는 물건인가

이 도구는 소스코드에서 보안 취약점을 찾고, 맞는지 다시 확인하고, 수정까지 돕는다. 명령줄에서 한 저장소를 점검할 수도 있다. 여러 저장소를 묶어 대량 점검하는 구성도 있다. 정기 보안 점검 때 사람이 훑던 목록을 먼저 골라 주는 심사 보조 도구에 가깝다.

스펙과 도입 조건

  • TypeScript SDK를 제공한다.
  • 실행에는 Node.js 22.13.0 이상과 Python 3.10 이상이 필요하다.
  • npm 패키지로 설치한다.
  • Dockerfile과 Docker Compose 구성을 제공한다.
  • CI에서는 OPENAI_API_KEY가 필요하다. 일반 사용은 로그인 방식도 쓴다.
  • 일부 사이버보안 요청과 보호된 findings는 Trusted Access for Cyber 승인이 필요하다.
  • 다른 추론 제공자도 지원한다. Amazon Bedrock, OpenRouter, Fireworks API 키를 쓸 수 있다.
  • 라이선스는 Apache-2.0이다.
  • 최신 릴리스는 npm-v0.1.25다.

이럴 때 쓰면 좋다

  • 배포 전 핵심 서비스 저장소를 야간에 자동 점검하고 취약점 후보를 먼저 추릴 때 유용하다.
  • 여러 개발팀 저장소를 한꺼번에 스캔해 중복 취약점과 재발 이력을 관리할 때 맞는다.
  • 사내 보안 기준 문서를 붙여 티켓 발행 전 심각도를 따로 분류하고 싶을 때 쓸 수 있다.

핵심 기능

  • 코드 디렉터리를 스캔해 취약점을 찾고 결과 보고서를 만든다.
  • findings 서비스를 띄워 결과와 임베딩을 저장하고 대시보드로 보여준다.
  • 자체 정책 문서로 findings 심각도를 다시 분류한 뒤 게시할 수 있다.

대안 대비 차별점

이 저장소는 스캔만 하는 데서 멈추지 않고 결과 저장, 중복 판정, 재검토까지 한 흐름으로 묶는다. findings 서비스는 스캐너와 같은 ghcr.io/openai/codex-security 이미지를 쓴다. 결과와 임베딩은 SQLite에 저장한다. 읽기 전용 대시보드는 5초마다 새로 고친다. 완료한 점검 결과는 findings 서비스로 올릴 수 있다. 같은 저장소 안이나 전체 저장소 범위에서 임베딩 유사도로 중복 후보를 찾는다. SDK와 dedupe 명령은 이 후보를 가져와 로컬에서 다시 검토하고, 승인한 중복 그룹을 저장한다. 이번 릴리스에서는 확인된 finding의 식별자를 스캔 간 비교에서도 유지한다. 큰 비교 작업은 텍스트를 자르지 않도록 배치 방식을 바꿨다. 맞춤형 모의 스캔도 추가했다. 인증이나 모델 호출 없이 표준 스캔 결과를 합성할 수 있다. 예산이 한도의 80%에 닿으면 대시보드나 SDK 콜백으로 총예산을 늘릴 수 있다.

사내 도입 체크

  • 외부 API 키를 쓸 수 있다. OPENAI_API_KEY나 다른 제공자 키를 붙이면 코드 정보가 외부로 나갈 수 있다.
  • findings 서비스는 SQLite에 결과와 임베딩을 저장한다. 저장 위치와 보존 정책은 확인이 필요하다.
  • 유지보수 주체는 OpenAI 조직이다.
  • 상용 정적 분석 도구와 일부 기능이 겹친다. 다만 모델 기반 중복 판정과 정책 분류 흐름은 별도 검토가 필요하다.

주요 용어

CLI(Command Line Interface): 화면 명령으로 실행하는 도구 SDK(Software Development Kit): 다른 프로그램에 기능을 붙이는 개발 도구 묶음 CI(Continuous Integration): 코드 변경 때 자동 점검을 돌리는 방식 임베딩(Embedding): 텍스트 의미를 숫자로 바꾼 표현 SQLite: 파일 기반 경량 데이터베이스
