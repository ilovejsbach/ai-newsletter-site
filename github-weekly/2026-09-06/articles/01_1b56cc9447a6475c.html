이 저장소는 개인용 트레이딩 에이전트를 표방한다. 웹 화면에서 전략을 돌리고, 시장 데이터를 읽고, 백테스트까지 수행한다. 최근 공개한 변경 내역은 새 기능보다 운영 오류 수정에 무게가 실렸다. 금융 업무에 AI를 붙일 때 무엇을 먼저 검증해야 하는지도 함께 드러난다.

무엇을 하는 물건인가

Vibe-Trading은 개인용 트레이딩 에이전트 저장소다. 사용자는 한 도구 안에서 시장 데이터를 조회하고 전략을 시험할 수 있다. 웹 화면과 API, MCP를 함께 제공해 연결 경로를 넓혔다. 비유하면 시세판, 리서치 메모, 모의투자 노트를 한 책상에 모아 둔 업무 도구에 가깝다.

스펙과 도입 조건

  • 언어는 Python이다.
  • Dockerfile이 있어 Docker 이미지 방식으로 배포할 수 있다.
  • API와 MCP를 제공한다.
  • 라이선스는 MIT다.
  • 최신 릴리스는 v0.1.14이며, 2026년 8월 20일에 공개됐다.

이럴 때 쓰면 좋다

  • 야간 배치 뒤에 전략 백테스트가 정상 종료했는지 웹 화면에서 빠르게 점검할 때 맞다.
  • 고객 자산운용 부서가 새 종목 규칙을 실험용으로 검증할 때 시장 데이터 조회와 모의 실행을 한곳에서 다룰 수 있다.
  • 사내 AI 실험팀이 모델 답변에 실제 시세 근거가 붙는지 검증 흐름을 살필 때 유용하다.

핵심 기능

  • 시장 데이터와 재무지표, 자금 흐름, 리서치 데이터를 불러와 대화와 실행에 쓴다.
  • 웹 UI에서 백테스트를 실행한다.
  • API와 MCP 경로로 외부 프로그램이나 에이전트와 연결한다.

왜 지금 주목받나

이번 주 변경 내역은 모델이 만든 허구 가격을 어떻게 걸러내는지에 집중했다. 영어와 중국어에서 판정이 다르던 검증 규칙을 맞췄고, 이미 읽은 데이터를 다시 못 읽는 문제도 고쳤다. 웹 UI에서 시작한 모든 백테스트가 aarch64에서 비정상 종료하던 문제도 수정했다. 비슷한 도구가 화면과 전략 생성에 초점을 둘 때, 이 저장소는 데이터 근거 검증과 실행 복구를 더 꾸준히 손봤다.

사내 도입 체크

  • 외부 API 호출 여부는 확인 필요다. README 발췌에는 API와 MCP 제공 사실만 있다.
  • 시장 데이터와 대화 내용이 외부 서비스로 나갈 수 있는지는 확인 필요다.
  • 유지보수 주체는 HKUDS 조직 계정으로 보인다.
  • 대체 가능한 상용 제품은 있다. 다만 이 저장소는 개인용 에이전트와 백테스트 결합에 초점을 둔다.

주요 용어

에이전트(Agent): 목표를 받아 도구를 호출하고 여러 단계를 스스로 수행하는 소프트웨어 백테스트(Backtesting): 과거 시장 데이터로 전략을 시험하는 절차 MCP(Model Context Protocol): 모델이 외부 도구와 연결할 때 쓰는 규약 그라운딩(Grounding): 모델 답변을 실제 데이터 근거와 대조하는 검증 aarch64: ARM 계열 64비트 CPU 환경
