금융 터미널은 시세 조회를 넘어서 분석 화면, 조사 도구, 경제 지표 탐색을 한자리에 모은다. 이 저장소는 그런 형태를 데스크톱 앱으로 구현했다. 무료판은 학습과 학술 용도로 공개하고, 기업용 비공개판은 따로 운영한다. 이번 주에는 v4.5.0 릴리스가 올라왔다.

무엇을 하는 물건인가

Fincept Terminal은 데스크톱 금융 분석 애플리케이션이다. 사용자는 여러 화면에서 시장 분석, 투자 조사, 경제 데이터를 탐색할 수 있다. 앱은 사용자 친화적 환경에서 상호작용형 분석을 지향한다. 비유하면 여러 금융 사이트 탭을 따로 열지 않고, 분석용 책상 하나로 묶어 둔 형태다.

스펙과 도입 조건

  • 언어는 C++20이다.
  • Qt6와 임베디드 Python 분석 환경을 쓴다.
  • 설치 형태는 Windows 설치 파일, Linux용 deb·rpm·포터블 설치 파일, macOS DMG다.
  • Dockerfile이 있다.
  • 지원 운영체제는 Windows 10/11 x64, Ubuntu 20.04+, Debian 11+, Fedora 36+, RHEL 9+, macOS 13+ Apple Silicon이다.
  • 저장소 메타데이터의 라이선스 표기는 NOASSERTION이다.
  • 무료판은 월 1회 릴리스를 예고했다.

이럴 때 쓰면 좋다

  • 자본시장 부서가 경제 지표와 시장 화면을 한 앱에서 훑으며 아침 브리핑 자료를 준비할 때 맞다.
  • 교육 조직이 신입 인력에게 금융 터미널 화면 구성을 익히게 할 때 학습용 도구로 쓸 수 있다.
  • 비개발 부서가 별도 코딩 없이 투자 조사 화면을 체험해 볼 때 적합하다.

핵심 기능

  • 시장 분석 화면을 제공한다.
  • 투자 조사 도구를 제공한다.
  • 경제 데이터 탐색 기능을 제공한다.

이번 릴리스에서 바뀐 점

이번 릴리스 노트 발췌에는 새 기능이나 삭제 기능보다 배포 패키지와 요구 환경이 중심으로 적혔다. 앱은 네이티브 C++20 금융 터미널로 소개했고, Qt6와 임베디드 Python, 50개 이상 화면을 내세웠다. 업그레이드 시에는 운영체제와 CPU 조건을 먼저 확인해야 한다. macOS는 Apple Silicon만 적었고, Windows는 x64 설치 파일을 배포한다.

플랫폼배포 파일설치 방식
Windows x64FinceptTerminal-*-setup*.exe설치 파일 실행
Linux (Debian/Ubuntu)FinceptTerminal-*-linux-x64.debdeb 패키지 설치
Linux (Fedora/RHEL)FinceptTerminal-*-linux-x64.rpmrpm 패키지 설치
Linux (portable)FinceptTerminal-*-linux-x64-setup.run실행 권한 부여 후 설치
macOS Apple SiliconFinceptTerminal-*.dmg 또는 setupDMG 열고 Applications로 이동

사내 도입 체크

  • 외부 API 호출 여부는 확인 필요다.
  • 데이터 반출 가능성은 확인 필요다. README 발췌에는 데이터 공급 방식이 없다.
  • 유지보수 주체는 Fincept-Corporation 조직 계정이다.
  • 비공개 Enterprise 에디션이 따로 있다. 실시간 브로커 라우팅과 SSO는 그쪽 기능으로 적었다.

주요 용어

AGPL-3.0: 네트워크로 제공해도 소스 공개 의무가 생길 수 있는 오픈소스 라이선스 Qt6: 데스크톱 화면을 만드는 C++용 개발 프레임워크 임베디드 Python: 응용프로그램 안에서 Python 분석 코드를 함께 실행하는 방식 SSO(Single Sign-On): 한 번 로그인으로 여러 시스템을 쓰는 방식
