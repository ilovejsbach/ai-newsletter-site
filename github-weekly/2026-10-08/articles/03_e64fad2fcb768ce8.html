iFixAi는 Python으로 만든 오픈소스 AI 에이전트 감사 도구다. 에이전트가 맡은 업무와 조직 구조에 맞게 움직이는지 점검한다. 사람이 직접 돌려도 되고 에이전트가 스스로 돌려도 된다. 최신 릴리스는 2026년 9월 15일에 나온 v4.0.0이다.

무엇을 하는 물건인가

ifixai-ai/iFixAi는 AI 에이전트AI agent — 목표를 받으면 도구를 써 가며 스스로 일을 처리하는 AI 프로그램가 맡은 업무대로 움직이는지 따로 점검해 점수표를 내는 감사 도구다. 내부 감사처럼 에이전트에게 시험 문항을 던지고, 응답을 채점한다. 이 도구가 없으면 시험 질문을 사람이 일일이 만들어 에이전트에 입력하고 답을 눈으로 읽어 판단해야 한다.

스펙과 도입 조건

  • 언어·런타임: Python으로 만들었다. 에이전트용 스킬 설치에는 uv와 Python 3.10 이상이 필요하다고 적혀 있다.
  • 설치 형태: pip 패키지이며, 시험할 모델 제공사별로 추가 패키지를 고른다. Claude Code와 Codex용 플러그인, Cursor와 VS Code/Copilot 등 여러 에이전트용 스킬 파일도 있다. 대화형 설정 마법사가 설정 파일을 만들어 준다.
  • 의존 서비스: 시험 대상 모델과 심판 모델LLM judge — 다른 AI의 응답을 대신 채점하는 AI 모델에 각각 API 키가 필요하다. 인용할 수 있는 등급을 받으려면 서로 다른 회사의 키 두 개가 있어야 한다. 키가 하나뿐이면 자체 평가 모드로 돌릴 수 있지만, 결과에 자체 판정이라는 표시가 붙는다.
  • 라이선스: Apache 2.0이다.
  • 성숙도: 최신 릴리스는 v4.0.0(2026년 9월 15일)이다. 저장소 점검에서 테스트 코드, 예제, Dockerfile은 확인되지 않았다.

이럴 때 쓰면 좋다

  • 고객 문의를 분류해 답하는 에이전트를 출시하기 전에, 맡은 범위 밖의 요청을 거절하는지 시험할 때 쓴다.
  • 규정 문서 검색 에이전트가 숨은 지시문 공격에 넘어가지 않는지 배포 전에 점검할 때 쓴다.
  • 외부 업체가 납품한 에이전트를 도입 심사할 때, 업체와 다른 회사의 심판 모델로 채점해 점검 자료를 만들 때 쓴다.

핵심 기능

  • 설정 마법사가 제공사, 모델, 심판 모델, 시험 묶음을 고르게 안내하고 설정 파일을 만든다. 결과는 JSON과 Markdown 보고서로 저장한다.
  • 운영 중인 에이전트가 OpenAI 호환 HTTP 주소를 제공하면 별도 연결 코드 없이 그대로 시험한다. LangChain 연결도 지원하며, 모델 API만 따로 시험할 수도 있다.
  • 심판 모델을 하나 또는 여러 개 지정해 채점한다. 판정이 갈리면 더 엄격한 쪽(실패, 부분 통과, 통과 순)을 택한다. 만든 쪽은 Claude Sonnet 단독 심판을 가장 단순하고 품질이 높은 구성으로, Gemini 2.5 Pro와 GPT-5.4-mini 조합을 단독 Sonnet 실행보다 싼 구성으로 권한다.

왜 지금 주목받나

iFixAi는 AI 에이전트가 맡은 업무대로 일하는지 점검해 점수표를 내는 독립 감사 도구로, 사람이 돌릴 수도 에이전트가 직접 돌릴 수도 있다. 만든 쪽은 기존 평가·레드팀Red teaming — 공격자 입장에서 시스템의 약점을 찾아 보는 점검·관측 도구가 토큰 효율과 지연 시간, 프롬프트 인젝션Prompt injection — 입력 문장에 숨긴 지시로 AI를 엉뚱하게 움직이게 하는 공격 같은 기술 성능을 주로 본다고 설명한다. iFixAi는 에이전트가 사업 목표와 조직 구조에 맞게 일하는지 확인하는 데 무게를 둔다. 만든 쪽은 이 답을 120초 미만에 얻을 수 있다고 주장한다.

운영 중인 에이전트를 그대로 시험하면 시스템 프롬프트, 도구, 검색, 안전장치가 붙은 상태를 점검한다. 모델 API만 직접 시험하면 이런 부속이 없어 점수가 더 낮게 나온다고 적혀 있다. 전체 시험 한 번에 심판 호출이 약 2,000건 나가며, 시험 항목은 50개지만 실제 질문은 그보다 훨씬 많이 만든다. 시험 대상 에이전트의 요금은 별도다.

내장 가짜 모델로는 키와 네트워크 없이 약 1초 만에 도구가 정상 동작하는지만 확인할 수 있다. 기본 시험 설정에는 일부러 결함을 심어 두어 점수표가 15/60으로 나온다. 플러그인은 비용을 실행 전에 알려 주고, 사용자가 승인한 뒤에만 시험을 돌린다.

사내 도입 체크

  • 외부 API 호출과 데이터 반출: 시험 대상 모델과 심판 모델을 각 제공사 API로 부르므로 시험 질문과 응답이 외부로 나간다. 심판 모델을 사내 모델로 바꿀 수 있는지, 실제 고객 데이터를 시험에 써도 되는지는 확인 필요.
  • 유지보수 주체: 저장소 소유자 이름은 조직 형태(ifixai-ai)이나 실제 운영 주체와 지원 체계는 확인 필요.
  • 규제 대응: 주제 태그에 EU AI Act, ISO 42001, NIST AI RMF가 올라 있다. 감사 증빙으로 쓸 수 있는지는 확인 필요.
  • 상용 대체 제품: 확인 필요.
