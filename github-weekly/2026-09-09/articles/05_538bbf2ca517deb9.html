이 저장소는 가상자산 거래 전략을 자동으로 실행하는 봇이다. 거래소 연결만 되는 도구가 아니다. 전략을 만들고, 과거 데이터로 시험하고, 운영 중 성과를 확인하는 흐름을 한곳에 모아 둔다. 다만 작성자는 교육 목적 소프트웨어라고 못 박았고, 실제 손익 책임도 지지 않는다.

무엇을 하는 물건인가

Freqtrade는 가상자산 거래 전략을 자동으로 돌리는 오픈소스 봇이다. 사용자는 주요 거래소를 붙이고, 웹 화면이나 Telegram으로 봇을 제어할 수 있다. 거래에 바로 돈을 넣기 전에 Dry-Run으로 먼저 돌려야 한다. 엑셀로 가설을 세우고 모의 계산까지 끝낸 뒤에야 결재를 올리는 절차와 비슷하다.

스펙과 도입 조건

  • Python 3.11 이상에서 돌아가며 Windows, macOS, Linux를 지원한다.
  • Docker 사용을 권장하며, 네이티브 설치 방법도 제공한다.
  • 거래소 연결이 필요하므로 외부 거래소 서비스 의존성이 있다.
  • 라이선스는 GPL-3.0이다.
  • 최신 릴리스는 2026.8이며 stable, develop, feat/* 브랜치를 따로 운영한다.
  • 최소 권장 사양은 메모리 2GB, 디스크 1GB, 2vCPU다.
  • sqlite로 상태를 저장한다.

이럴 때 쓰면 좋다

  • 디지털자산 신사업 검토 팀이 실제 주문 없이 Dry-Run으로 전략 운영 절차를 먼저 익힐 때 쓸 수 있다.
  • 야간 배치처럼 정해진 규칙을 반복 실행하듯 매수·매도 규칙을 과거 데이터로 백테스트할 때 맞다.
  • 운영 담당자가 사무실 밖에서 Telegram으로 봇 상태와 손익, 잔고를 빠르게 확인할 때 편하다.

핵심 기능

  • Dry-Run으로 실제 자금 없이 봇을 실행한다.
  • 백테스트로 매수·매도 전략을 과거 데이터에 적용한다.
  • 머신러닝과 FreqAI로 전략 파라미터 최적화와 적응형 예측 모델 구성을 지원한다.

이번 릴리스에서 바뀐 점

이번 릴리스 노트 발췌에는 전략 함수의 @informative 호출 캐시를 추가했다고 적었다. 이 변경은 기본값으로 켜지며, 해당 함수 안에서 데이터프레임 외 작업을 하는 전략에만 동작 변화가 생길 수 있다. Pairlists 쪽에는 VolatilityFilter에 lookback_period와 lookback_timeframe 지원을 넣었다. 발췌가 중간에서 끊겨 있어 삭제 기능이나 호환성 주의사항의 전체 목록은 추가 확인이 필요하다.

사내 도입 체크

  • 거래소와 직접 연결하는 구조라 외부 API 호출과 주문 전송이 발생한다.
  • 시장 데이터와 주문 정보가 거래소로 오가므로 데이터 반출 범위는 거래소별 설정을 따져봐야 한다.
  • 유지보수 주체는 개인이 아니라 프로젝트 팀으로 보이지만, 정확한 조직 운영 체계는 확인 필요다.
  • 상용 자동매매 플랫폼과 일부 기능이 겹치지만, 사내 통제와 책임 체계는 별도로 설계해야 한다.

주요 용어

백테스트(Backtesting): 과거 시장 데이터로 전략을 다시 돌려 보는 검증 방식 드라이런(Dry-Run): 실제 주문 없이 가상으로만 실행하는 시험 모드 웹UI(WebUI): 브라우저에서 상태를 보고 조작하는 화면 텔레그램(Telegram): 메신저로 명령을 보내 봇을 제어하는 방식 머신러닝(Machine Learning): 데이터 패턴으로 규칙을 조정하는 기법
