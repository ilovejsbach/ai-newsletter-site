Anthropic, Mythos 5를 보안 도구로 넓힌다

Anthropic이 사이버 방어팀에 Claude Mythos 5 접근을 넓히는 계획을 내놨다. 핵심은 모델을 아무에게나 직접 열지 않고, 방어 결과물만 전달하는 경로를 늘리는 것이다. Claude Security, 파트너 보안 제품, 오픈소스 보안 지원 기금, 검증 프로그램 확장이 이번 발표에 묶였다.

핵심 브리핑

Claude Mythos 5는 이제 Claude Security에서 쓸 수 있다. Anthropic은 파트너사의 사이버 방어 도구에도 곧 넣겠다고 밝혔다. 오픈소스 소프트웨어 보안을 돕는 3,500만 달러 규모 크레딧 기금도 시작한다.

Claude Security는 Claude Enterprise 고객에게 공개 베타로 제공 중이다. 보안 스캔은 기존 요금제 안에서 일반 토큰 사용량으로 과금한다. 별도 부가 상품은 없다.

Enterprise 관리자는 관리자 콘솔에서 Claude Security를 켤 수 있다. 사용자는 claude.ai/security에서 저장소를 골라 Claude Mythos 5로 스캔을 실행한다. 결과에는 CWE 분류, 신뢰도, 심각도, 수정 제안이 포함된다.

수정 적용은 웹의 Claude Code에서 이어서 진행할 수 있다. 다만 대화형 패치는 조직이 Claude Code에서 접근 권한을 가진 모델로 실행한다. Mythos 스캔 자체가 다른 화면으로 Mythos 접근을 넓혀 주지는 않는다.

Anthropic은 모든 패치를 사람이 검토하고 승인한 뒤에만 적용할 수 있다고 밝혔다. 사용자는 취약점 패치 제안이나 보안 경보 같은 정해진 결과를 받는다. 모델 자체를 자유롭게 조작하는 방식은 막아 둔다.

Defender Advantage Fund(0xDAF)는 오픈소스 보안을 돕는 조직에 3,500만 달러의 Claude 크레딧을 제공한다. 지원 분야는 널리 쓰이는 프로젝트의 실시간 취약점 패치, 다른 프로젝트가 따라 할 수 있는 스캔·패치 자동화, 더 강한 보안 접근 실험의 세 가지다.

주요 트렌드

Anthropic은 강한 보안 모델을 직접 개방하기보다 제품 안에 숨겨 넣는 방식을 택했다. 사용자는 모델과 대화하지 않고, 도구가 정한 작업의 결과만 받는다. 보안 분야에서는 이 구조가 오용 방지와 확산 속도를 함께 맞추려는 절충안으로 보인다.

사업 구조도 눈에 띈다. Anthropic은 자사 서비스인 Claude Security를 강화하는 동시에 파트너 보안 제품에 Mythos 5를 넣으려 한다. 병원, 공공 인프라, 금융 시스템, 소프트웨어 공급망을 지키는 팀이 이미 쓰는 도구로 들어가야 확산이 빠르다는 판단이다.

접근 정책도 단계적으로 푼다. Cyber Verification Program은 앞으로 몇 주 안에 Opus와 Sonnet에서 더 넓은 dual-use 기능을 허용할 계획이다. Mythos급 접근은 그다음 단계로 예고했다.

업계의 움직임

여러 매체가 함께 다룬 사건이다. The New Stack과 MarkTechPost는 Anthropic이 Claude Security 취약점 스캐너에 Mythos 5를 넣은 점과, 직접 모델 접근 없이 엔터프라이즈 보안 스캔을 제공한다는 점을 함께 짚었다.

Anthropic은 기존 보안 기술·서비스 파트너와 새 파트너를 모아 제품 통합을 추진 중이다. 보안 제품이나 서비스를 만드는 회사는 관심 등록을 할 수 있다.

시사점과 체크포인트

금융IT 기업에는 이 배포 방식이 특히 중요하다. 취약점 분석은 강한 모델이 유용하지만, 모델을 자유롭게 다루게 하면 공격 시나리오 생성 위험도 커진다. 이번 구조는 결과물만 노출해 그 위험을 낮추려는 설계다.

우리 회사라면 다음을 먼저 확인할 필요가 있다.

  • 코드 저장소를 외부 서비스에 어떻게 연결하는지
  • 스캔 결과와 패치 제안이 어디에 저장되는지
  • 사람이 승인하기 전 자동 적용 경로가 없는지
  • 조직이 가진 모델 접근 권한이 Claude Code와 어떻게 분리되는지

0xDAF 같은 크레딧 기금은 오픈소스 의존도가 높은 회사에도 간접 영향이 있다. 우리가 쓰는 핵심 오픈소스가 지원 대상이 되면 패치 속도가 빨라질 수 있다. 반대로 어떤 프로젝트가 지원을 받는지는 아직 공개되지 않았다.

주요 용어

Claude Security: 코드 취약점 스캔과 패치 제안을 제공하는 Anthropic 기능 CWE(Common Weakness Enumeration): 소프트웨어 취약점 유형 분류 체계 Cyber Verification Program: 검증된 보안 조직에 일부 보호장치를 완화해 주는 접근 프로그램 dual-use cyber work: 방어와 공격에 모두 쓸 수 있는 사이버 작업 Project Glasswing: 중요 소프트웨어 방어 조직에 고급 모델을 먼저 제공한 프로그램
