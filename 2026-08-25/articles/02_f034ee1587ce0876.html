Anthropic, Mythos 5를 보안 도구로 넓힌다

Anthropic은 강한 보안 모델을 더 많은 방어팀에 열어주되, 직접 접근은 엄격히 막는 쪽을 택했다. 보안팀은 기존 도구 안에서 취약점 탐지와 패치 제안을 받는다. 모델 자체를 자유롭게 조작할 수는 없게 설계했다.

핵심 브리핑

Anthropic은 Claude Mythos 5를 Claude Security에 넣었고, 곧 파트너사의 사이버 방어 도구에도 탑재하겠다고 밝혔다. 동시에 오픈소스 보안 강화를 위해 3,500만 달러 규모 크레딧 펀드를 시작한다. Cyber Verification Program도 몇 주 안에 넓힐 계획이다.

이번 발표의 핵심은 직접 접근을 줄이고 방어 결과만 넓게 제공하는 구조다. Anthropic은 가장 위험한 경우를 사용자가 모델에 직접 접속할 때로 봤다. 반면 취약점 패치안이나 보안 경보처럼 정해진 산출물만 받으면 위험이 더 낮다고 설명했다.

Claude Enterprise 고객은 이제 Claude Security에서 Mythos 5로 코드 저장소를 검사할 수 있다. 이 기능은 퍼블릭 베타 상태다. 별도 부가 상품 없이 기존 요금제의 일반 토큰 사용량으로 과금한다.

  • 관리자는 관리자 콘솔에서 Claude Security를 켤 수 있다
  • 사용자는 claude.ai/security에서 저장소를 골라 검사한다
  • 결과에는 CWE 분류, 신뢰도, 심각도, 수정 제안이 포함된다
  • 수정 적용은 Claude Code에서 진행할 수 있다
  • 모든 패치는 사람이 검토하고 승인해야 반영된다

Anthropic은 Defender Advantage Fund(0xDAF)로 3,500만 달러 크레딧을 제공한다. 지원 대상은 널리 쓰이는 오픈소스 프로젝트의 실제 취약점 패치, 스캔·패치 자동화, 더 강한 보안 접근 실험이다. 초기에는 소수의 대형 시범 지원부터 시작하며, 수혜 기관은 몇 주 안에 공개할 예정이다.

주요 트렌드

이번 발표는 강한 모델을 넓게 푸는 대신, 보안 제품 안에 숨겨 넣는 사업 방식을 보여준다. Anthropic은 병원, 공공설비, 금융 시스템, 소프트웨어 공급망을 지키는 팀이 쓰는 기존 도구에 Mythos 5를 연동하겠다고 밝혔다. 최종 사용자는 모델과 대화하지 않고, 제품이 만든 결과물만 받는다.

이 구조는 접근 정책과 유통 경로를 동시에 설계한 사례다. Claude Fable 5로는 범용 접근을 열되 이중용도 보안 작업은 막았고, Mythos 5는 더 좁은 인터페이스로 방어 기능만 확장한다. 모델 경쟁이 성능 경쟁에서 끝나지 않고, 어떤 표면에 어떤 권한으로 배포하느냐까지 옮겨간 셈이다.

업계의 움직임

여러 매체가 함께 다룬 사건이다. The New Stack과 MarkTechPost는 모두 Claude Security 취약점 스캐너에 Mythos 5가 들어갔고, 사용자가 모델에 직접 접근하지 않는 점을 핵심으로 짚었다. Anthropic도 파트너 보안 업체와 서비스 업체가 자사 제품에 Mythos 5를 넣도록 협업 중이라고 밝혔다.

시사점과 체크포인트

금융IT 기업에는 이 배포 방식이 특히 중요하다. 모델을 직원에게 직접 열어주지 않고, 취약점 탐지와 패치 제안만 결과물로 받으면 내부 통제가 쉬워진다.

검토할 질문은 다음과 같다.

  • 우리 코드 저장소를 외부 스캔에 연결할 수 있는지
  • 결과물과 원본 코드의 보관 범위를 어떻게 나눌지
  • 사람이 승인해야 하는 단계가 현행 변경관리와 맞는지
  • 보안팀, 개발팀, 감사팀이 같은 증적을 볼 수 있는지

아직 파트너 도구 목록과 세부 통제 방식은 모두 공개되지 않았다. Mythos급 접근이 Cyber Verification Program에서 언제, 어떤 조건으로 열릴지도 후속 공지가 필요하다.

주요 용어

이중용도(Dual-use): 방어와 공격에 모두 쓸 수 있는 기술 성격 가드레일(Guardrail): 위험한 사용을 막기 위한 제어 장치 CWE(Common Weakness Enumeration): 소프트웨어 취약점 유형 분류 체계 퍼블릭 베타(Public beta): 정식 출시 전 공개 시험 단계 소프트웨어 공급망(Software supply chain): 개발에 쓰는 오픈소스, 라이브러리, 빌드 도구까지 포함한 공급 구조
