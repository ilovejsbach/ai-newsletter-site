3~12초 시연 한 번으로 배우는 GEN-1.5

Generalist AI가 로봇 파운데이션 모델 GEN-1.5를 연구 공개했다. 핵심은 시연 한 번으로 새 물리 작업을 수행한다는 점이다. 제품 출시가 아니라 연구 발표라서 공개 가중치와 API는 없다. 지금은 직접 제휴로만 접근할 수 있다.

핵심 브리핑

이 모델은 3~12초짜리 시연 하나를 30초 문맥 창에 넣으면 새 작업을 바로 수행한다. 입력은 영상, 센서, 언어, 고유수용감각이다. 출력은 100Hz 행동 궤적이다. 회사는 이 능력이 8개월 넘게 이어진 물리 상호작용 사전학습에서 나왔다고 설명했다.

연구팀은 이 방식을 physical prompting이라 불렀다. 센서 흐름과 행동 궤적을 예시로 넣고, 남은 문맥 창에는 현재 관찰을 계속 채운다. 모델은 경사하강 없이 바로 행동한다. 작업별 프로그램도 없다.

핵심 수치는 다음과 같다.

  • 사전학습 모델 그대로: 10개 조작 작업에서 평균 59% 성공, 표준편차 ±10%
  • 작업별 데이터 5분과 경사하강 10단계: 평균 83%, 표준편차 ±9%
  • 한 작업 보류 평가에서 데이터 1분과 경사하강 1단계: 66.5%

연구팀은 이 능력을 위해 구조를 바꾸지 않았다고 밝혔다. 인컨텍스트 학습을 유도하는 구조 변경도 없었고, 메타러닝 루프도 없었다. 즉흥 행동을 유도하는 보조 목적도 없었다. 대상 작업은 단순하고 짧은 구간이라는 한계도 함께 적었다.

현재 제공 상태는 제한적이다.

  • 공개 가중치 없음
  • API 없음
  • 가격 페이지 없음
  • 셀프서비스 제품 없음
  • Generalist AI 자체 로봇과 데이터 엔진에서만 운영
  • 사용 희망 시 직접 제휴 필요

스펙과 도입 조건

이 발표는 제품 도입 정보보다 연구 조건이 중요하다. 모델은 대형 멀티모달 구조다. 집, 창고, 공장 환경에서 수집한 물리 상호작용 데이터로 8개월 이상 계속 사전학습했다. 작업별 적응은 초저데이터 조건에서 이뤄졌다.

연구팀은 계산량 변화도 공개했다. 로봇 정책 적응에는 보통 수만 단계의 경사하강이 필요했다. 그런데 이 모델은 10단계만으로도 보류 작업의 가중치가 0.15% 미만만 변했다. 연구팀은 이것이 새 표현을 만드는 일보다, 이미 배운 지식을 다시 배치하는 과정에 가깝다고 봤다.

전이 결과도 세 가지를 강조했다.

  • 조합 일반화: 따로 기록한 두 시연을 이어 넣으면 모델이 사이 연결 동작을 스스로 만든다.
  • 제로샷 시뮬레이션-실물 전이: 시뮬레이터에서 만든 시연을 실제 로봇의 프롬프트로 쓴다.
  • 사람-로봇 모방: 사람 손 시연을 로봇 손 동작으로 재현한다.

다만 실제 도입 조건은 아직 비어 있다. 공개 가중치, API, 가격, 배포 방식이 모두 없다. 사내 파일럿을 바로 꾸릴 수 있는 상태는 아니다.

업계의 움직임

아직 공개된 반응은 확인되지 않았다. 회사는 이 결과를 연구 신호로 제시했고, 배포보다는 직접 제휴 경로만 열어뒀다.

시사점과 체크포인트

금융IT 기업은 로봇 자체보다 학습 방식의 변화에 주목할 만하다. 작업별 코드 개발이나 장시간 재학습 대신, 짧은 시연과 소량 데이터로 절차를 바꾸는 접근이 다른 자동화 영역에도 번질 수 있다.

우리 회사 관점의 점검 항목은 다음과 같다.

  • 현업 자동화팀: 반복 절차를 짧은 시연 예시로 바꿔 설명할 수 있는가
  • 데이터 거버넌스팀: 센서·영상 데이터를 저장하고 재사용할 기준이 있는가
  • 리스크팀: 성공률 59%와 83%가 어떤 실패 비용을 뜻하는지 계산했는가
  • 전략기획팀: 직접 제휴 모델만 가능한데, 벤더 종속을 감수할지

한계는 분명하다. 작업은 단순하고 짧은 구간이다. 공개 가중치와 API가 없다. 성능 검증도 회사 발표 기준이다. 그래서 지금은 도입 여부를 서두르기보다, 현업 절차를 짧은 예시로 넘기는 방식이 문서 처리, 상담 보조, 운영 자동화 같은 다른 AI 도구에도 통하는지 따져보는 편이 낫다.

주요 용어

파운데이션 모델(Foundation model): 여러 작업에 공통으로 쓰도록 대규모 데이터로 먼저 학습한 모델 인컨텍스트 프롬프팅(In-context prompting): 모델 가중치를 바꾸지 않고 예시를 문맥에 넣어 작업을 시키는 방식 파인튜닝(Fine-tuning): 특정 작업에 맞게 추가 데이터로 모델을 더 학습하는 과정 시뮬레이션-실물 전이(Sim-to-real): 시뮬레이터에서 얻은 학습이나 예시를 실제 장비에 적용하는 것 고유수용감각(Proprioceptive input): 로봇 관절 위치·속도처럼 자기 몸 상태를 나타내는 입력
