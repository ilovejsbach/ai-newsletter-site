메타, Muse Code를 월 5달러로 정식 전환

Muse Code는 대규모 코드 저장소에서 변경 계획을 세우고, 코드를 쓰고, 검증까지 맡는 코딩 에이전트다. 메타는 이 제품을 정식 출시하며 구독제와 SDK를 함께 추가했다. 핵심 변화는 낮은 월 구독료와 외부 도구 연동 범위 확대다.

핵심 브리핑

메타는 월 5달러부터 50달러까지 3개 구독제를 추가하고 Muse Code를 베타에서 정식 서비스로 전환했다. 이 제품은 Meta의 Muse Spark 1.2 모델을 바탕으로 돌아간다. 터미널에서 쓰는 방식이며, 큰 코드베이스의 복잡한 작업을 처리하도록 설계했다.

메타는 정식 출시와 함께 세 가지 기능을 더했다. 세션 간 메시징은 서로 다른 작업 세션이 문맥과 상태를 직접 공유한다. Workflows는 여러 전문 에이전트를 큰 작업에 배치하고 중간 결과를 넘겨 최종 결과 하나로 돌려준다. 개발자는 전용 제어 화면에서 이 에이전트들을 보고 방향을 바꿀 수 있다. 되감기 기능은 대화와 코드 변경을 이전 시점으로 되돌린다.

  • Everyday Usage: 월 5달러
  • High Usage: 월 15달러, 사용량 3배
  • Power Usage: 월 50달러, 사용량 10배
  • 월 5달러 요금제: 5시간마다 보통 10~50회 요청
  • 요청 수는 작업 복잡도에 따라 달라짐

메타는 기존 종량제도 유지한다. Standard 요금제는 입력 100만 토큰당 1.25달러, 출력 100만 토큰당 4.25달러다. Contributor 요금제는 입력 100만 토큰당 0.10달러, 출력 100만 토큰당 0.20달러다. 다만 Contributor 사용자는 프롬프트와 응답을 메타 제품 개선에 쓰는 조건에 동의해야 한다.

메타는 SDK도 개발자 미리보기로 공개했다. 이 SDK를 쓰면 외부 소프트웨어가 Muse Code 세션을 시작하고, 다시 열고, 지시를 보내고, 응답을 처리할 수 있다. 메타는 외부 클라이언트가 Muse Code 세션과 통신하는 기반 규약으로 Muse Session Protocol도 공개했다.

주요 트렌드

메타는 가격에서 먼저 승부를 걸었다. 월 5달러 시작 구독제는 Claude Code와 Codex의 대표 구독제보다 명목 가격이 낮다. Anthropic은 Claude Code를 월 20달러 Pro에 넣고, 월 100달러와 200달러 요금제에서 사용량을 5배와 20배로 늘린다. OpenAI도 Codex를 월 20달러 Plus에 포함하고, 월 100달러와 200달러 요금제에서 사용량을 5배와 20배로 올린다.

다만 구독료만으로 실제 생산성을 바로 비교하기는 어렵다. Anthropic은 절대 요청 횟수를 공개하지 않고, 5시간·주간 제한을 함께 둔다. OpenAI는 GPT-5.6 Sol 기준으로 5시간마다 Plus 10~100회, Pro 5x 50~500회, Pro 20x 200~2,000회라고 적었지만 모델과 작업 복잡도, 문맥, 추론, 도구 사용에 따라 달라진다고 밝혔다. 메타의 10~50회 추정치도 같은 조건 비교로 바로 맞추기 어렵다.

메타는 기능 확장 속도도 빠르다. CLI 베타를 낸 지 한 달도 안 돼 외부 앱에 심는 SDK와 통신 규약까지 내놨다. Anthropic과 OpenAI도 각자 SDK를 제공하므로, 코딩 에이전트 시장은 이제 단독 앱이 아니라 플랫폼 경쟁으로 옮겨가고 있다.

업계의 움직임

무함마드 나바이드 시니어 머신러닝 엔지니어는 링크드인에서 메타의 비례형 가격 구조가 단순하다고 평가했다. 가격이 오르면 사용량도 같은 비율로 늘어나는 점을 긍정적으로 봤다. 반면 Msty AI의 공동창업자 겸 CEO 아쇼크 겔랄은 가격이 매우 낮지만, 메타가 데이터를 더 모으려는 전략일 수 있다고 우려했다.

Anthropic과 OpenAI는 이미 Claude Agent SDK와 Codex SDK를 내놨다. 메타의 이번 발표는 이들과 같은 층위에서 개발자 생태계를 붙잡으려는 대응으로 읽힌다.

시사점과 체크포인트

금융IT 기업은 월 구독료보다 데이터 처리 조건을 먼저 봐야 한다. Contributor 요금제처럼 프롬프트와 응답을 제품 개선에 쓰는 조건은 내부 코드와 운영 정보가 섞일 때 바로 제약이 된다.

도입 검토 때는 개발 생산성과 보안 운영을 함께 점검할 필요가 있다.

  • 정보보호팀: 프롬프트·응답 보관 정책과 재학습 사용 여부 확인
  • 개발플랫폼팀: IDE, 사내 포털, 배치 도구에 SDK를 붙일 수 있는지 검토
  • 아키텍처팀: 대규모 저장소 작업에서 세션 공유와 Workflows가 실제로 유효한지 검증
  • 구매팀: 구독제와 종량제 중 어느 방식이 조직 사용 패턴에 맞는지 비교

같은 매체가 Muse Code와 Claude Code를 같은 3개 작업으로 비교했을 때, Muse Code는 비용은 낮았지만 토큰을 더 많이 썼고 리팩터링 결과도 더 약했다. 죽은 코드를 남긴 사례도 있었다. 우리 회사가 평가할 때도 가격표 대신 실제 업무 시나리오로 완료율과 수정량, 검증 시간까지 함께 재야 한다.

주요 용어

코딩 에이전트(Coding Agent): 코드 작성·수정·검증을 맡는 AI 도구 SDK(Software Development Kit): 다른 앱에 기능을 붙이게 해주는 개발 도구 모음 토큰(Token): 모델이 입력과 출력을 처리할 때 세는 단위 페이애즈유고(Pay-as-you-go): 쓴 만큼 비용을 내는 과금 방식 CLI(Command Line Interface): 터미널 명령으로 쓰는 실행 환경
