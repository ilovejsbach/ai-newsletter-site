SolarWM, 143만 클립으로 세계 모델 공개 기반 제시

SolarWM은 상호작용형 영상 세계 모델을 만들기 위한 공개 기반을 제시한 연구다. 문제는 데이터셋마다 시간 길이와 카메라 정보, 자막 형식이 달라 섞어 학습하기 어렵다는 데 있다. 연구진은 데이터를 먼저 하나의 계약 형식으로 맞추고, 여러 영상 생성 백본에 같은 학습 절차를 얹는 방식을 택했다.

핵심 브리핑

SolarWM은 데이터 준비부터 장시간 추론까지 아우르는 공개 프레임워크다. 목적은 서로 다른 영상 데이터와 모델 구조를 한 기준에서 학습하고 비교하게 만드는 데 있다. 연구진은 10개 데이터셋에서 143만 개 표준 클립을 추려 하나의 정렬된 형식으로 바꿨다.

이 형식은 시각 관측값, 카메라 기하 정보, 자막, 품질 메타데이터, 선택 기록, 출처 정보를 함께 담는다. 연구진은 데이터 원천 처리와 혼합 구성을 분리해 재현성을 높였다고 설명했다. 같은 카메라 조건부 입력, 학습, 추론 인터페이스 위에서 4개 모델을 구현했다.

  • 데이터셋 수: 10개
  • 표준 클립 수: 143만 개
  • 모델 크기: 50억~330억
  • 기반 백본: Wan2.2, LTX-2.5, MiniMax-H3
  • 학습 입력 길이: 5초 시퀀스
  • 결과 롤아웃 길이: 수분~수시간

연구진은 세 단계 학습 절차도 제시했다. 이 절차는 양방향 적응, teacher-forced 자기회귀 초기화, 분포 정합 증류를 결합한다. 연구진은 이렇게 만든 인과형 모델이 5초 길이 시퀀스로 학습한 뒤에도 수분에서 수시간 범위의 실시간 상호작용 롤아웃을 지원한다고 밝혔다. 데이터, 파이프라인, 레시피, 가중치, 프레임워크도 함께 공개했다.

스펙과 도입 조건

이 연구는 오픈 공개 범위가 넓다. 데이터, 파이프라인, 학습 레시피, 모델 가중치, 프레임워크를 함께 내놨다. 다만 배포 라이선스와 실제 하드웨어 요구 사항은 발췌문에 나오지 않았다.

모델은 하나로 고정되지 않는다. Wan2.2, LTX-2.5, MiniMax-H3 같은 서로 다른 영상 생성 백본에 공통 인터페이스를 씌웠다. 연구진은 각 백본의 고유 표현 방식과 학습 목표는 유지했다고 적었다. 그래서 SolarWM의 핵심은 단일 모델 성능보다, 이질적인 모델을 같은 데이터 계약과 학습 절차에 올리는 데 있다.

실제 도입 관점에서 바로 확인할 정보는 아직 부족하다. 추론 비용, 배포 방식, 상용 사용 조건은 발췌문만으로는 판단하기 어렵다.

업계의 움직임

아직 공개된 반응은 확인되지 않았다.

시사점과 체크포인트

금융권이 이 연구를 바로 제품으로 들여오기는 이르다. 대신 여러 출처의 시계열 데이터를 하나의 계약 형식으로 맞추는 설계는 내부 AI 프로젝트에 참고할 만하다.

우리 회사가 비슷한 구조를 검토한다면 먼저 데이터 계층을 봐야 한다.

  • 데이터플랫폼팀: 출처별 시간 축과 메타데이터를 공통 형식으로 맞출 수 있는지 점검
  • AI연구팀: 서로 다른 모델 백본에 공통 평가 절차를 둘 수 있는지 검토
  • 인프라팀: 50억~330억 규모 모델 실험이 가능한 자원과 저장 구조 확인
  • 준법·보안팀: 공개 데이터와 사내 데이터 혼합 시 출처 추적이 유지되는지 확인

이번 연구는 긴 영상 생성 자체보다 재현성 확보에 무게를 둔다. 사내에서도 모델 교체보다 데이터 표준과 실험 기록 체계를 먼저 정리해야 비교와 재학습이 쉬워진다.

주요 용어

세계 모델(World Model): 환경 변화를 예측하며 다음 장면을 이어 만드는 모델 장시간 추론(Long-horizon Inference): 짧은 입력을 바탕으로 긴 구간을 계속 생성하는 방식 자기회귀(Autoregressive): 앞선 출력 결과를 바탕으로 다음 출력을 이어 만드는 방식 증류(Distillation): 큰 모델의 동작을 다른 모델에 옮겨 학습시키는 기법 백본(Backbone): 여러 응용 모델이 공통으로 쓰는 핵심 구조
